## 一、项目概述

### 1.1 一句话介绍

《虫虫装修》是一款以“休闲化搜打撤 × 装修模拟经营”为核心双循环的休闲冒险游戏。玩家扮演一只小瓢虫，进入被寄生植物侵袭的人类遗迹，利用手电、地形和有限背包搜索材料并安全撤离，再把旧物制造成家具，为流浪小动物建造一座会记住共同生活的家。

### 1.2 核心情绪

游戏围绕“守护与陪伴”展开：门外是迷雾、废墟和未知威胁，门内是灯光、家具与等待玩家回家的伙伴。野外的危险让归家更有分量，家园的温暖又让每一次冒险都有明确意义。

### 1.3 体验支柱

| 体验支柱 | 玩家感受 | 主要承载系统 |
|-|-|-|
| 有目标的冒险 | 我知道这次出门要找什么 | 家具追踪、任务、材料缺口 |
| 有取舍的撤离 | 我还能再拿一点，但也可能带不回家 | 光源、负重、背包、宝箱风险、敌人 |
| 有结果的装修 | 我带回的旧物真的改变了空间 | 制造、网格摆放、套装与扩建 |
| 有回应的陪伴 | 我的选择被小动物看见并记住 | AI记忆、对话、日记、家具互动 |
| 有方向的成长 | 家变好以后，我也能走得更远 | 贴纸、能力投资、新房间、新区域 |

## 二、核心玩法机制说明

### 2.1 核心循环

```text
小动物提出需求 / 玩家追踪家具
        ↓
系统显示蓝图、材料与数量缺口
        ↓
进入野外：探索、采集、开箱、周旋
        ↓
管理背包、负重、光源与撤离风险
        ↓
成功回家：物资入仓、新蓝图解锁
        ↓
工作台制造 → 家园装修摆放
        ↓
小动物互动、AI回应并产出贴纸
        ↓
贴纸投资能力或家园扩建
        ↓
新房间、新需求、新蓝图、新区域
        ↺
```

该循环分别回答三个持续游玩问题：

- 为什么出门：为某位伙伴、某件家具或某次扩建补齐明确缺口。
- 为什么回家：只有成功撤离，物资才能永久入仓并转化为空间变化。
- 为什么再次出门：新家具、伙伴心愿、能力升级和房间扩建会产生下一轮需求。

### 2.2 单轮体验节奏

单次野外探索以 2—4 分钟为目标，形成“安静搜索—发现价值—风险升高—主动撤离—归家兑现”的短局结构。家园阶段不设强制倒计时，玩家可自由制造、装修和陪伴小动物。一紧一松的节奏让轻度玩家获得刺激，但不会长期处于高压状态。

### 2.3 野外探索机制

#### 2.3.1 视野与信息压力

野外覆盖战争迷雾。玩家可以看见手电光圈外的环境轮廓、建筑和宝箱信号，但看不见潜伏的敌人；墙体会遮挡光线，转角与路线结构则形成信息盲区。

敌人发现玩家时，通过清晰的动作、画面和音效反馈提示危险状态，让玩家能够及时决定迎击或撤离。

#### 2.3.2 手电：照明、时限与防身三合一

手电同时承担三种功能：

1. 照亮道路并发现资源、敌人和交互物。
2. 能量持续下降，光圈逐渐缩小，形成撤离时限。
3. 持续照射近距离敌人可将其驱散或击败，是玩家唯一的正面防身方式。

玩家没有传统武器。普通敌人的一对一驱散时间控制在约 3 秒，使反应及时的玩家可以快速解除单个威胁；但玩家被敌人直接接触即判定本次冒险失败，因此同时面对多个敌人时，绕行、隐蔽和逃跑通常优于硬抗。

低电量阶段通过能量条、光圈收缩、画面边缘变暗和提示音逐级预警。系统始终保留撤离方向提示，避免玩家因单纯迷路而失败。

#### 2.3.3 资源获取

野外资源分为两类：

| 来源 | 信息状态 | 主要产出 | 风险定位 |
|-|-|-|-|
| 地面资源 | 拾取前即可辨认 | 少量基础材料 | 稳定、低风险 |
| 宝箱 | 搜索完成前未知 | 大量材料、家具、蓝图、特殊道具 | 高价值、高风险 |

地面资源用于维持基础制造，单点产量较少；宝箱需要玩家停留并等待格子逐一揭示，期间仍可能被敌人发现。玩家必须一边查看奖励，一边留意周边环境与视野变化。

部分宝箱为“陷阱箱”。打开后可能释放强力敌人，且同一局中开箱次数越多，触发风险越高。这个规则把“贪心”转化为玩家可感知的决策：继续开箱可能获得稀有蓝图，也可能让已经超重的自己陷入追逐。

#### 2.3.4 背包、负重与安全格

背包由 6 格主背包与 2 格安全背包组成。材料可在同类格中堆叠，家具与蓝图占用独立空间。所有携带物共同计算负重。

- 负重越高，移动越慢，撤离和摆脱追击越困难。
- 玩家可以丢弃物品以立刻减负，也可以重新排序和合并堆叠。
- 关键蓝图或稀有物可手动放入安全背包。
- 冒险失败后，安全背包内容保留；主背包内容掉落，并提供一次返回原区域追回的机会。
- 成功撤离后，全部物资进入家园永久仓库。

这套温和惩罚既保留“带走才算赢”的紧张感，也避免一次失败抹去过多进度。

#### 2.3.5 敌人与周旋

敌人系统采用统一、易理解的基础交互规则。

- 敌人拥有直接发现玩家的范围。
- 敌人发现玩家后，按基础规则判定是否追击；若决定追击，会先经过短暂反应时间。
- 玩家可通过移动、拉开距离或使用手电处理威胁。
- 玩家被敌人直接接触时，本次冒险失败。
- 敌人被手电持续照射后会受到伤害，击败后掉落宝箱。

敌人的核心职责是为收集和撤离制造压力。统一规则控制操作门槛，让玩家把注意力放在路线、背包、光源与撤离时机的综合判断上。

#### 2.3.6 冲刺与隐蔽

冲刺消耗体力，是玩家穿过开阔区、摆脱追击和主动争取高价值目标的共同资源。地形转角、墙体与不同路线为玩家提供周旋空间。玩家必须决定把体力用于主动争取奖励，还是保留为最后的逃命手段。

#### 2.3.7 撤离与结算

玩家可以在满足撤离条件后主动回家。成功撤离后依次反馈：

1. 本次带回的材料、家具、蓝图和特殊物。
2. 新蓝图及新图鉴条目。
3. 已经满足制作条件的追踪家具。
4. 尚缺少的材料与推荐来源。
5. 下一步可进入的制造、装修或任务入口。

结算不是单纯统计页，而是野外奖励转换为家园目标的桥梁。

### 2.4 家园装修与模拟经营

#### 2.4.1 家园定位

家园是安全区、经营场和情感中心。它由室外公共区域与小动物独立房间组成。每个房间对应一位住户的性格、经历和需求；随着主线与扩建推进，废弃空间会逐步变成跨物种共同生活的聚落。

#### 2.4.2 工作台与蓝图

玩家需要同时满足“已经学习蓝图”和“仓库材料足够”才能制造家具。图鉴负责展示完整家具套装、未解锁条目和来源线索；工作台只展示已经获得蓝图的可制造项目。

玩家最多可追踪 3 件家具，每件家具最多需要 4 类材料。追踪目标会同步显示在工作台、家园任务栏与野外 HUD 中，确保玩家从出门到回家都知道当前缺口。

制造完成后，家具进入仓库首位，并提供“立即摆放”入口，缩短制造与空间变化之间的操作距离。

#### 2.4.3 双模式装修

| 模式 | 镜头与操作 | 主要体验 |
|-|-|-|
| 行走模式 | 玩家控制瓢虫在房间中移动，与小动物和家具近距离互动 | 沉浸、观察、陪伴 |
| 装修模式 | 镜头拉远，显示网格、仓库和编辑工具 | 高效摆放、旋转、回收与布局 |

家具具有尺寸、占格、风格、套装、房间限制和互动标签。玩家可以自由表达，不存在唯一最优布局；数值奖励鼓励尝试新家具与满足住户需求，但不强迫玩家复制固定答案。

#### 2.4.4 贴纸经济

贴纸是游戏的核心硬通货，但不从野外直接掉落。它来自小动物对玩家建设行为的反馈：首次摆放新家具、完成套装、满足明确心愿或完成房间阶段目标时，小动物会产生贴纸气泡。

玩家靠近领取气泡时，会先收到一句角色化感谢或评价，再看到贴纸进入货币栏。贴纸主要用于两类投资：

- 能力投资：升级手电续航与视野、背包与负重、机动与隐蔽。
- 家园扩建：解锁新房间、新蓝图、新住户需求与新区域线索。

装修因此同时产生审美结果、情感结果和成长结果，但小动物不会被设计成按时产钱的工具。

### 2.5 小动物陪伴与 AIGC 机制

#### 2.5.1 设计目标

AIGC 不替代任务规则，也不承担胜负判定，而是让小动物能根据玩家真实做过的事情给出差异化表达。玩家感受到的不是“NPC 会聊天”，而是“它看见了我刚才的付出，而且以后还记得”。

#### 2.5.2 可记录事件

系统将以下事实写入结构化记忆：

- 玩家从哪次冒险带回了什么物品。
- 玩家是否安全归来，是否曾在该角色任务中失败。
- 玩家制造、摆放、移动或回收了哪件家具。
- 角色第一次使用某件家具的时间与反应。
- 玩家完成过的心愿、送礼、抚摸、对话与关键剧情。
- 当前房间风格、关系阶段、角色心情和近期事件。

#### 2.5.3 生成与控制流程

```text
玩家行为触发事件
  → 规则层确认事件真实有效
  → 更新角色短期记忆与长期关系摘要
  → 注入角色设定、当前心情、关系阶段和事实记录
  → 生成简短的第一人称角色反馈
  → 一致性校验
  → 展示台词 / 校验失败则重试或使用模板兜底
```

关键剧情、任务条件、奖励数量与角色关系数值均由确定性规则控制。AI表达基于经过验证的真实事件与角色记忆，并由一致性校验约束；预设台词作为稳定表达层，与生成内容共同保证核心循环连续运行。

### 2.6 成长与任务机制

#### 2.6.1 三条成长线

| 成长线 | 方式 | 对循环的影响 |
|-|-|-|
| 主角成长 | 花费贴纸升级手电、背包、机动 | 提高探索效率与容错，但不取消风险 |
| 家园成长 | 扩建房间、解锁蓝图和公共区域 | 增加装修空间并产生新需求 |
| 关系成长 | 对话、送礼、完成心愿和剧情 | 解锁角色故事、纪念家具与更深反馈 |

#### 2.6.2 任务分层

- 长期主线：推进区域、救助伙伴并揭开人类遗迹与寄生植物的秘密。
- 中期支线：围绕每位小动物的过去、家庭和个人目标展开。
- 短期心愿：提供收集、制造、装修和探索中的即时目标。
- 情感任务：由心情与共同记忆触发，不阻塞主线。

所有任务最终回到同一条行为链：“知道伙伴需要什么—去危险处带回来—把家变好—得到回应”。

## 三、关卡设计

### 3.1 世界空间结构

第一大章“水獭一家篇”采用“中心家园 + 三层风险区”的放射式关卡结构。家园是永久安全中心；玩家通过门、道路和逐步打通的地下捷径进入野外。区域越深，资源价值、地形复杂度与撤离成本越高。后续小动物章节将在这一结构上扩展新的区域、资源主题与角色目标。

```text
                         [区域三：高危探索区]
                    高级资源 / 复杂洞穴 / 强追逐
                              ↕
                         [区域二：旧聚落]
                    复杂路线 / 建筑高差 / 中级资源
                              ↕
                         [区域一：森林边缘]
                    教学采集 / 清晰路线 / 低压敌人
                              ↕
                    [家园：房屋与室外安全区]
```

随着推进，区域二和区域三各可开启一条通往家园的洞穴捷径。捷径既缩短重复路程，也在叙事上表现“玩家正在把危险世界重新连接成可生活的空间”。

### 3.2 通用关卡元素

| 元素 | 功能 |
|-|-|
| 地面采集点 | 提供稳定资源与连续确认感 |
| 普通宝箱 | 提供高价值随机奖励与停留风险 |
| 陷阱箱 | 制造贪心决策和局内事件 |
| 高墙 | 阻挡移动与光线，塑造视野盲区 |
| 矮墙 / 树丛 | 可透光或翻越，支持绕行与甩脱 |
| 草丛 / 高位掩体 | 提供路线遮挡和周旋空间 |
| 山洞 | 快速穿越或连接家园的捷径 |
| 高低差 | 提供观察点、逃生路线和视觉层次 |
| 路灯、荧光蘑菇、篝火 | 提供方向、安全预期与光照博弈 |
| 营救点 | 连接关卡挑战与角色入驻剧情 |

资源、交互物和危险物在轮廓与色彩上必须清晰区分。地图不能只靠黑暗制造难度，路径开口、地标、微光和环境提示要持续告诉玩家“我正在向目标靠近”。

### 3.3 区域分层

#### 3.3.1 区域一：森林边缘——理解规则

区域一是教学与正反馈区。路径结构清晰，以基础材料、少量宝箱和低压敌人为主。玩家学习手电视野、采集、背包、基础开箱、草丛隐藏和撤离。

- 资源：中量基础材料，少量中级材料。
- 地形：高墙形成主路径，少量草丛、矮墙和高低差。
- 敌人：数量少，反应窗口长，追击路线可预判。
- 关卡目标：救出第一位水獭伙伴，并完成第一轮“探索—制造—装修—反馈”。

#### 3.3.2 区域二：旧日聚落——利用信息

区域二增加废弃建筑、高低差和岔路。玩家需要在多个资源点之间规划路线，并开始面对更高的探索与撤离压力。

- 资源：大量基础材料、较多中级材料、少量高级资源。
- 地形：建筑内外、高低平台、窄巷、洞穴和多条绕行路线。
- 敌人：沿用基础敌人规则，通过数量与位置提高压力。
- 关卡目标：找到并带回第二位水獭；开启第一条家园捷径。

#### 3.3.3 区域三：高危探索区——综合运用

区域三集中测试光源、负重、冲刺和路线判断。入口处被破坏的门与更复杂的地形提前传达危险升级。

- 资源：中高级资源、稀有家具和关键蓝图。
- 地形：复杂建筑、多个洞穴、大量高低差与可破坏路线。
- 敌人：沿用基础敌人规则，通过关卡布置形成高压力追逐。
- 关卡目标：在高压力事件中找到出路，并由第三位水獭从地下打开逃生洞穴。

### 3.4 新手关卡完整流程

#### 阶段一：建立“家”的目标

1. 开场短片交代瓢虫受人类家居图册启发，寻找一处废弃房屋开始独立生活。
2. 玩家在安全屋内学习移动、观察、清扫、工作台和仓库。
3. 室外庭院展示两个尚未开启的地洞，预告长期地图连接目标。
4. 门外传来微弱求救声，任务从“熟悉系统”自然转为“寻找声音来源”。

#### 阶段二：第一次野外探索

1. 玩家离开庭院，首次看见战争迷雾和手电光圈。
2. 路边基础材料以明显轮廓出现，玩家按交互键完成采集。
3. 求救声再次出现，地形与微光把玩家引向受伤的水獭。
4. 玩家观察附近敌人的位置与当前路线，寻找接近水獭的机会。
5. 抱起水獭后触发首次追逐，系统通过清晰路线教会玩家冲刺与撤离。
6. 玩家返回家园，完成首次撤离结算。

#### 阶段三：第一次制造与装修

1. 水獭需要休息，但房内没有合适的床。
2. 系统自动追踪“小窝”，展示蓝图、已有材料和缺口。
3. 家中教学宝箱补足首次制造所需材料，确保玩家顺利完成第一件家具。
4. 制造完成后直接进入装修模式，玩家拖拽、旋转并确认摆放。
5. 水獭使用小窝，给出角色化反馈并产生第一枚贴纸。
6. 玩家领取贴纸，看到能力升级与房间扩建的后续目标。

首轮流程让玩家在 10—15 分钟内明确理解：“我冒险，不是为了囤积材料，而是为了让某个具体的伙伴住得更好。”

### 3.5 关卡节奏控制

单局使用四类节奏节点：

| 节点 | 频率 | 作用 |
|-|-|-|
| 逼近信号 | 约每 15—30 秒 | 通过声音、微光或地形提示提供方向 |
| 小收获 | 每段路线 1—2 次 | 地面资源维持正反馈 |
| 心跳节点 | 每局少量 | 宝箱与营救点带来高价值决策 |
| 撤离警告 | 光源进入低量阶段 | 迫使玩家结束贪心并规划返程 |

随机资源、敌人与宝箱负责提高重复游玩的变化，主线营救、捷径和关键追逐则固定布置，保证叙事节奏与教学下限。

### 3.6 失败与防挫

- 新手救援段的追击路线明确，敌人速度和数量低于正式关卡。
- 关键任务材料设置保底，避免随机掉落造成卡关。
- 玩家失败时明确提示安全背包已保留、掉落物位置和追回规则。
- 低光阶段始终显示撤离方向，不把迷路当作主要惩罚。
- 支线与情感任务不会阻塞主线。
- 连续失败时可调整陷阱箱或敌人压力，但不改变关键路线结构。

## 四、交互逻辑

### 4.1 全局状态流转

```text
家园行走
  ├─ 与小动物交互 → 对话 / 送礼 / 领取贴纸 / 查看日记
  ├─ 打开工作台 → 图鉴 / 制造 / 分解 / 追踪
  ├─ 进入装修模式 → 拖拽 / 旋转 / 回收 / 确认
  └─ 从出口出发 → 野外探索

野外探索
  ├─ 接近资源 → 采集
  ├─ 接近宝箱 → 搜索与背包整理
  ├─ 遭遇敌人 → 照射 / 隐蔽 / 冲刺 / 甩脱
  ├─ 到达撤离点 → 结算 → 家园行走
  └─ 冒险失败 → 失败结算 → 家园行走
```

### 4.2 基础操作

| 场景 | 玩家意图 | 输入 | 系统响应 |
|-|-|-|-|
| 通用 | 移动 | WASD / 摇杆 | 角色移动，更新脚步声与负重速度 |
| 通用 | 交互 | E / 手柄主交互键 | 根据当前最高优先级对象执行交互 |
| 野外 | 调整照射方向 | 鼠标 / 右摇杆 | 手电朝向变化，刷新可见范围与敌人受光状态 |
| 野外 | 冲刺 | 冲刺键 | 消耗体力并提高移速 |
| 野外 | 打开背包 | B / 背包按钮 | 打开主背包与安全背包 |
| 家园 | 打开工作台 / 图鉴 | B / 常驻图标 | 进入工作台并切换到装修视角 |
| 家园 | 进入家具编辑 | 长按家具 | 显示网格、旋转、回收和确认控件 |

所有按键支持后续重映射；移动端或手柄版本使用相同的意图层，不改变底层状态逻辑。

### 4.3 情境交互优先级

当多个对象同时处于交互范围时，系统按以下顺序确定目标：

1. 主线营救对象或当前任务关键物。
2. 正在攻击或需要即时处理的危险对象。
3. 宝箱、出口、工作台等完整功能入口。
4. 小动物、家具、普通采集点。
5. 彩蛋与环境观察点。

当前目标使用轮廓高亮与短提示确认。若同级对象重叠，系统优先选择屏幕中心最近者，并允许玩家切换目标。

### 4.4 采集交互

1. 玩家进入采集范围，物体高亮并显示名称与交互提示。
2. 按 E 后播放极短采集动作。
3. 系统优先合并同类堆叠，再寻找空格。
4. 成功时显示物品、数量、当前追踪缺口和负重变化。
5. 背包已满时不吞物品，提示玩家整理、丢弃或放弃。

追踪材料使用专属角标，使玩家立即知道这次拾取推进了哪件家具。

### 4.5 宝箱与陷阱交互

1. 玩家按 E 开始搜索，角色在原地翻找。
2. 宝箱格子逐一揭示，未揭示前不显示内容。
3. 搜索期间玩家仍可观察周边，并可随时中断逃离。
4. 若触发陷阱，界面立即收起，危险方向出现强提示。
5. 普通奖励揭示后，玩家在“宝箱容器—主背包—安全背包”之间拖拽物品。
6. 关闭界面后，未取走物品保留到本局结束。

### 4.6 背包交互

| 操作 | 结果 |
|-|-|
| 拖到空格 | 移动物品 |
| 拖到同类物品 | 合并堆叠，超出部分留在原格 |
| 拖到不同物品 | 交换位置 |
| 拖到安全背包 | 将关键物品设为失败后保留 |
| 拖到丢弃区 | 丢到地面，并提供短时撤销机会 |
| 点击物品 | 查看名称、重量、用途、来源与追踪关系 |

整理背包时野外时间不暂停，以保留决策压力；新手教学和无障碍选项可提供减速模式。

### 4.7 敌人交互与反馈

- 视野外：玩家不能直接看见敌人，保持战争迷雾带来的信息压力。
- 发现玩家：敌人播放明确反应反馈，再根据当前基础规则进入追击。
- 受光：敌人出现受击反馈，持续照射后被击败并掉落宝箱。
- 接触玩家：明确呈现失败原因，再进入结算，避免瞬间切屏导致“我为什么失败”的困惑。

### 4.8 制造与追踪交互

1. 玩家打开工作台，系统同时显示图鉴、仓库和当前房间。
2. 点击家具卡片，查看蓝图状态、所需材料、仓库数量和来源。
3. 材料足够时点击制造；不足时可加入追踪。
4. 制造成功后家具进入仓库首位。
5. 玩家选择“立即摆放”或继续制造。
6. 被追踪家具在工作台置顶，材料缺口同步到野外 HUD。

### 4.9 装修交互

1. 玩家从仓库拖出家具，进入预览状态。
2. 可放置格显示正常颜色；碰撞、越界或房间不匹配时显示红色。
3. 玩家拖动位置、点击旋转并确认摆放。
4. 首次有效摆放后记录“装修事件”。
5. 相关小动物根据距离、需求和偏好触发动画、气泡或短对话。
6. 若满足贴纸条件，小动物头顶出现可领取气泡。

移动已有家具时，系统保留其原位置，只有确认后才提交新布局；取消操作则恢复原状，防止误操作破坏房间。

### 4.10 小动物交互

玩家靠近小动物后，可根据状态选择对话、送礼、抚摸、查看日记或领取贴纸。交互分为两类：

- 阻塞式交互：主线剧情、重要支线和玩家主动打开的完整对话。
- 非阻塞式交互：装修反馈、迎接回家、家具使用和日常短气泡。

AI生成在后台异步完成，不阻塞移动和装修。请求期间可先播放表情或动作；超时后使用符合当前角色与事件的模板台词。

### 4.11 信息反馈原则

每个关键动作都形成“操作—状态变化—意义解释”三层反馈：

| 动作 | 状态反馈 | 意义反馈 |
|-|-|-|
| 拾取材料 | 图标、数量、负重变化 | 追踪家具缺口减少 |
| 获得蓝图 | 蓝图揭示动画 | 新家具可制造 |
| 成功撤离 | 物资入仓 | 回家后能完成什么 |
| 摆放家具 | 网格确认、房间变化 | 小动物使用并回应 |
| 领取贴纸 | 货币飞入栏位 | 可升级能力或扩建 |
| 开启捷径 | 地图路线更新 | 更深区域变得可持续探索 |

## 五、玩法闭环示例

水獭妹妹害怕黑暗，希望房间里有一盏灯。玩家在图鉴中追踪对应灯具，得知还缺两种制造材料。进入区域二后，玩家先从地面资源中取得一种材料，又发现一个可能包含另一种材料的宝箱。此时背包已经偏重、手电进入低电量，附近还有敌人活动。玩家判断路线后冒险完成开箱，将任务材料放入安全背包，并经由刚刚开启的洞穴捷径撤离。

回家后，结算界面提示夜灯已可制造。玩家在工作台完成制作并直接摆到妹妹床边。妹妹第一次在夜晚独自走到灯下，AI根据“玩家曾在低电量状态下带回关键材料”“这是她第一次收到照明家具”“当前信任阶段”生成简短感谢，并把这件事写入日记。玩家领取贴纸，升级手电续航，于是下一次能更深入地探索。

这一段完整串联了角色需求、材料追踪、关卡机制、风险取舍、装修结果、AI反馈和成长投资，也是《虫虫装修》最小而完整的核心体验。

## 六、设计总结

《虫虫装修》的核心不是把“搜打撤”“装修”和“AI对话”并列堆叠，而是让三者互相产生意义：玩家因为某个具体伙伴而冒险，因为冒险带回的旧物而改变家，因为家发生变化而获得被看见、被记住的陪伴反馈。最终，每一件家具既是功能物，也是玩家与角色共同经历的记忆锚点。
