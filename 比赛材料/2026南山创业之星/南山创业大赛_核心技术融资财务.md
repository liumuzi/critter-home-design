## 核心技术

### 技术来源

**自主研发 + 开源大模型集成**

本项目的核心技术分为两个层面：

1. **游戏引擎层（自主研发）**：基于 Unity 引擎进行全栈游戏开发，包括野外探索系统（AI怪物行为树、背包动态管理、撤离判定）、家园装修系统（自由摆放引擎、家具碰撞检测、风格匹配算法）、任务与成长系统等。所有核心玩法逻辑均为团队从零搭建。

2. **AI叙事层（开源模型 + 自研架构）**：小动物NPC的情感反馈系统采用"规则模拟层 → 叙事生成层 → 表现层"三层架构。其中叙事生成层调用兼容 OpenAI Chat Completions 协议的大语言模型（当前为 google/gemini-2.5-flash-lite），团队自主研发了结构化上下文构建、事件驱动触发、一致性校验与降级兜底等全套工程管线。模型可替换，架构不依赖于单一模型供应商。

**技术亮点**：
- 三层解耦架构：规则层（确定性逻辑）+ AI层（生成式表达）+ 表现层（UI渲染），各层可独立迭代、独立降级
- 一致性校验管线：生成 → 校验 → 重试 → 模板兜底，确保AI输出不与游戏事实冲突
- 事件驱动而非自由对话：AI只在玩家完成具体操作后触发反馈，避免"AI聊天机器人喧宾夺主"
- 低延迟优先：选用轻量模型，响应时间控制在游戏可接受范围内

详细技术说明见 `2026光子游戏大赛/AI_技术报告_提交版.md`。

## 财务预测（单位：万元人民币）

### 统一测算口径

- **发售时间**：2027年Q4，Steam PC端全球首发。
- **销量口径**：统一使用“付费售出套数”；退款、折扣和区域价格的影响合并反映在平均成交额中。
- **平均成交额**：基准测算按每套人民币80元（含税、含平台）计算；不是标价承诺。
- **收入口径**：表内“营业收入（含平台）”指消费者支付总额；Steam 30%平台费在营业成本中单列，公司实收为消费者支付总额的70%。
- **时间口径**：日历年度和“首发12个月”严格分开。日历2027年仅含约2.5个月销售；首发12个月为2027Q4—2028Q3。
- **利润口径**：净利润 = 消费者支付总额 - 平台费 - 人力/研发 - 营销 - 其他运营 - 税金及附加。所有情景表均沿用这一公式。
- **预测属性**：所有销量、收入和利润均为内部经营目标，并非订单、承诺收入或已实现业绩。

> 编制基础：
> - 团队维持7人核心规模，关键节点补充QA等短期岗位
> - 对标产品：《Moonlighter》（Digital Sun，~8人初创期，100万+套，$19.99定价，有发行商11 bit studios）、《潜水员戴夫》（MINTROCKET/Nexon子公司，500万+套）
> - 产品**2027年Q4** Steam首发，买断制定价约¥70-100（$15-$20），Steam平台分成30%
> - 2028年起叠加赛季DLC收入（每赛季¥30-50，年3-4赛季，DLC购买率按30%估算）
> - 营业税金及附加按简化综合税率估算（约5%，以扣除平台分成后的净收入为基数）
> - **营业收入为含平台分成的总额（Gross Revenue），平台渠道费在营业成本中单独列示**

### 各年说明

**2026年（研发期）**
- 营收：产品尚未上线，无收入。
- 成本：7人核心团队及阶段性支持的人力成本约¥200万 + 软件工具/设备/外包/办公约¥50万。
- 净利润：-250万，为早期研发投入，由团队自筹 + 天使轮融资覆盖。

**2027年（Q4首发年）**
- 营收：Steam于Q4首发，约2.5个月销售窗口，预估销量约**5万套**（首发月集中爆发 + 年末假日季），消费者支付总额约¥400万。扣除Steam 30%后公司实收¥280万。
  - 对标依据：《Moonlighter》首发12个月约50万套（有发行商），我们按自发行折算30%，首发12个月目标15万套。日历2027年仅含其中2.5个月。
- 成本：全年人力¥240万 + 营销¥80万（Q3预热+Q4首发推广）+ 平台渠道费¥120万 + 其他¥40万 = ¥480万。
- 净利润：-80万，**日历年内小幅亏损**——全年养人但仅约2.5个月销售窗口。首发12个月（2027Q4-2028Q3）预计实现净利润约¥340万。

**2028年（首个完整销售年）**
- 营收：日历2028年新增本体销量约**17万套**，本体消费者支付总额约¥1,360万；叠加首个DLC收入约¥240万，合计约¥1,600万。扣除Steam 30%后公司实收约¥1,120万。截至2028Q4，本体累计销量约22万套。
  - 增长驱动：口碑传播 + Steam长尾效应 + 赛季DLC拉动回流。
  - 对标：《Moonlighter》累计100万+套（含Switch/主机/移动端）；22万套是本项目截至2028Q4的PC端累计目标，不是2028年单年销量。
- 成本：渠道分成¥480万 + 团队维持8-10人（人力约¥350万）+ 持续营销（约¥120万）+ 运营/其他（约¥150万）。
- 净利润：约¥465万；需由愿望单、Demo转化和发售数据逐步校准。
