## 当前结论

半决赛商业计划书正文以 `虫虫家装_商业计划书_半决赛.md` 为唯一来源。当前推荐的路演交付文件为：

- `甲壳虫工作室+虫虫家装+半决赛路演PPT_产品优势重构版.pptx`：10页8分钟主路演，优先证明情绪反差、因果循环、伙伴关系、传播结构和团队匹配；另含1页进展验证与3页财务答辩附录，全部隐藏；
- `甲壳虫工作室+虫虫家装+半决赛路演PPT_产品优势重构版.pdf`：仅导出10页主路演，供提交和现场备份。

`甲壳虫工作室+虫虫家装+半决赛路演PPT_视觉精修版.pptx` 保留为上一轮视觉稿，不再作为当前首选。此前的南山路演稿、参考稿、备份及其PDF统一收纳在 `其他PPT（废稿与参考）/`，均不作为提交版本；其中商业计划书同步版仍作为当前版本隐藏财务附录的生成来源。

提交前仍需由主讲人确认姓名、日期、视频播放与南山主体迁入承诺。评委画像及改稿依据见 `2026南山创业之星_半决赛评审分析.md`。

## PPT脚本维护

- `scripts/generate_nanshan_semifinal_ppt_advantage.ps1` 生成当前推荐的产品优势重构版；将Demo、19份问卷与发售计划降为辅助证据，主线改为“产品为何特别—为何会传播—为什么团队能做出来—资金如何放大已验证优势”。
- `scripts/generate_nanshan_semifinal_ppt_visual.ps1` 生成上一轮视觉精修版；主线优先呈现“外面危险—逃回家—伙伴回应—把家变好”的情绪反差，图片统一按原始比例插入，并从 `其他PPT（废稿与参考）/` 中的内容同步版复制3页隐藏财务附录。
- 视觉配色固定使用商业计划书已有的暖纸色、深青、低饱和蓝绿和陶土橙，不再套用高饱和自动配色。浅色信息页复用参考PPT中提取的蓝色手绘边缘纹理，源文件位于 `assets/ppt/reference_textures/`。
- 第8页主线只保留“发售前看愿望单、发售后看销量”及5万愿望单/15万套两个主数字；5万、约8万、15万、30万套完整销量情景留在隐藏答辩附录。
- `scripts/generate_nanshan_slide8_standalone.ps1` 只生成一页独立候选稿 `第8页_愿望单与销量口径_单页.pptx`，用于确认“5万愿望单不等于15万套销量”的版式；不会读取或覆盖视觉精修版主文件。
- `scripts/generate_nanshan_semifinal_ppt.ps1` 生成与半决赛商业计划书同步的12页主路演，并追加3页隐藏的预算、分期拨付和经营情景附录；主路演中的演讲备注也在脚本内维护。
- `scripts/revise_existing_nanshan_ppt.ps1` 负责重建现有参考稿中的半决赛核心页面。
- `scripts/add_nanshan_cost_appendices.ps1` 负责重建愿望单与融资页，并追加成本、市场和获客依据。
- 重建页面必须通过 `ClearSlide` 删除原有形状后再添加内容，避免PowerShell内置 `Clear` 别名导致旧页面与新页面叠加。

## 半决赛商业计划书打印版

- 正文唯一来源：`虫虫家装_商业计划书_半决赛.md`。
- LaTeX 模板、排版过滤器、构建脚本和输出文件位于 `LaTeX/`。
- 在 PowerShell 中执行 `./LaTeX/build_business_plan.ps1 -TexOnly`，即可重新生成同名 `.tex`。
- 在 PowerShell 中执行 `./LaTeX/build_business_plan.ps1`，即可重新生成同名 `.tex` 和可直接打印的 `.pdf`；生成 PDF 需要本机已安装 XeLaTeX/latexmk。
- 默认构建会清理 `.aux`、`.log` 等中间文件；需要保留排错文件时使用 `./LaTeX/build_business_plan.ps1 -KeepBuildFiles`。
- PDF 按 A4、双面装订友好的页边距设计；打印时选择“实际大小”或“100%”，不要再次缩放页面。
