# 版本取舍与待定问题

## 新旧判断原则

本轮整理优先采用创建/更新时间较新的文档，并结合内容是否和当前目标一致判断可信度。2026年5月以后文档通常反映光子切片后对核心循环、驱动力、工作台和野外的最新修正；1-3月文档多用于补足系统细节。

## 高优先级新口径

- 游戏定位为“野外探索 × 家园装修”的双循环休闲冒险，不是纯装修。
- 小动物作为家园侧情感反馈和叙事驱动力，不作为独立第三玩法板块。
- 家具追踪、撤离结算、制造后摆放、贴纸反馈、蓝图解锁、家园扩建是当前最重要的循环修复点。
- 主角能力投资采用三个固定栏位：手电/光源、背包/负重、机动/隐匿。
- 手电/光源是当前野外限制和能力升级的核心系统，需要优先落地。
- 怪物系统计划重新设计，旧怪物A/B/C和完整状态机不作为当前实现方案。
- 野外最新方向强调“逼近感”：采集点信号、宝箱心跳、跨局缺口。
- 工作台和图鉴需要分工，追踪最多 3 个家具，每个配方最多 4 种材料。

## 降权或废弃内容

| 内容 | 处理 | 原因 |
|-|-|-|
| 小动物每日固定产出资源 | 降权 | 会削弱情感定位，把小动物工具化 |
| 完整图腾系统 | 暂缓 | 与饰品/鞋子/护甲重复，Demo阶段过重 |
| 旧怪物A/B/C与复杂状态机 | 暂停 | 9.15计划仍要求确认/迭代怪物方案，且旧稿过重 |
| 旧鞋子/护甲/图腾/饰品并行成长 | 不采用为V1主结构 | 与三个固定能力栏位冲突 |
| 旧版“文档垃圾站”内容 | 仅作历史参考 | 目录本身标记为垃圾站，存在旧稿风险 |
| 纯装修作为唯一卖点 | 不采用 | 3.31讨论和5月后文档都指向综合体验 |
| 无限制野外探索 | 不采用 | 会破坏短局决策和资源经济 |

## 当前缺口

### 叙事

- 序章文本未完整落地。
- 第一只小动物的具体需求、性格、房间目标还不明确。
- 世界观“为什么需要装修小动物的家”需要一句强钩子。

### 野外

- 手电/光源限制的具体数值、包装和UI未定。
- 手电/光源升级档位和生效时机未定。
- 宝箱内容表、概率、价值分档未定。
- 区域一刷新规则未定。
- 地图地标、采集点信号和迷雾表现需要美术/关卡同步。

### 家园

- 贴纸产出公式、领取频率和上限未定。
- 房间扩建、蓝图解锁和地图解锁的关系未定。
- 小动物家具互动的触发规则未定。

### UI

- 追踪多个家具时材料合并方式未定。
- 图鉴、工作台、仓库的最终交互稿需要确认。
- 回家结算UI和制造后直接摆放流程需补详细状态图。

### 数值

- 背包初始格数存在 6 / 8 两种历史口径。
- 三个主角能力的贴纸消耗、等级上限和效果参数需要配置表。
- 机动/隐匿能力是否主动释放或被动生效需要确认。
- 怪物重做后，光源/声音/负重如何影响危险需要重新设计。
