# 物品、背包与经济

## 文档定位

本文是物品、背包与贴纸经济的总文档，只说明三套系统如何组成循环。详细实现拆到三个子文档中：

## 最新版本口径

- 舒适度系统已删除，不再作为成长、解锁或UI进度条。
- 贴纸是唯一核心硬通货，承担原先“成长反馈/解锁推进”的主要职责。
- 野外只产出材料、家具、蓝图等原料，不直接产出贴纸。
- 家园通过“摆放家具 + 小动物反馈”产出贴纸。
- 蓝图用于解锁家具制作权限，和材料共同决定能否制作家具。
- 贴纸主要用于投资能力和家园扩建；售卖/变现是弱路径，只做救急和加速。

## 总循环

```text
野外探索
  -> 获得材料 / 家具 / 蓝图 / 特殊物
  -> 背包装载与安全背包取舍
  -> 撤离回家，进入仓库
  -> 工作台制作家具或解锁新配方
  -> 摆放家具，小动物产生贴纸反馈
  -> 贴纸投资能力 / 家园扩建
  -> 能力提升或空间扩大
  -> 新材料需求 / 新蓝图需求 / 新小动物需求
  -> 下一轮野外探索
```

## 三个系统的边界

### 物品系统负责“是什么”

物品系统定义材料、家具、蓝图、饰品/装备、特殊家具、贴纸相关兑换物等对象。它负责物品字段、堆叠规则、来源、用途和解锁关系。

### 背包系统负责“怎么带回来”

背包系统定义野外临时容器和家园永久仓库。它负责格子数量、拖拽交互、安全背包、负重、死亡掉落、撤离入库等流程。

### 经济系统负责“为什么继续玩”

经济系统定义贴纸如何产出、领取、消耗和投资。它负责把家园装修转化为下一次野外探索的能力和目标。

## V1实现优先级

1. 先实现背包格子、拾取、丢弃、撤离入仓库。
2. 再实现材料、家具、蓝图三类核心物品。
3. 再实现工作台制作：蓝图已解锁 + 材料足够 -> 制作家具。
4. 再实现小动物贴纸气泡：家具摆放后进入可领取状态。
5. 最后实现贴纸投资：装备升级和家园扩建。

## 待定问题

- 贴纸是否能直接购买材料，还是必须先售卖变现再购买。
- 小动物产出贴纸是否按现实时间、游戏日、装修事件或混合规则触发。
- 特殊家具 Buff 是否可叠加，以及上限如何保护。
- 家园扩建除贴纸外是否需要额外条件，例如蓝图、主线或小动物入住进度。
