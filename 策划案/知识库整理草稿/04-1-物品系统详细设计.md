# 物品系统详细设计

## 系统定位

物品系统定义游戏里所有可获得、可携带、可消耗、可制作、可摆放、可兑换的对象。V1重点支持材料、家具、蓝图、特殊家具 Buff、贴纸和装备升级材料。

## 物品大类

| 类型 | 是否进背包 | 是否进仓库 | 主要来源 | 主要用途 |
|-|-|-|-|-|
| 材料 | 是 | 是 | 采集点、宝箱 | 工作台制作家具、升级装备 |
| 家具 | 是 | 是 | 宝箱、工作台制作 | 家园摆放、小动物产贴纸 |
| 蓝图 | 是，拾取后可自动学习 | 是/图鉴记录 | 宝箱、扩建、任务 | 解锁家具制作权限 |
| 特殊家具 | 是 | 是 | 稀有宝箱、任务 | 摆放后提供轻微野外 Buff |
| 贴纸 | 否，进入货币栏 | 否 | 小动物反馈 | 投资能力、家园扩建、弱路径变现 |
| 装备/饰品 | 是 | 是 | 投资升级、宝箱、任务 | 提升野外能力 |

## 通用数据字段

| 字段 | 类型 | 说明 |
|-|-|-|
| item_id | string | 唯一ID |
| name | string | 显示名 |
| item_type | enum | material / furniture / blueprint / special_furniture / equipment / currency |
| icon | asset_id | UI图标 |
| stackable | bool | 是否可堆叠 |
| max_stack | int | 最大堆叠数，非堆叠为1 |
| weight | float | 背包负重计算 |
| rarity | enum | common / rare / epic / special |
| source | enum[] | 采集、宝箱、任务、工作台、扩建等 |
| description | string | 图鉴/背包说明 |

## 材料

材料是工作台制作的基础输入。区域一材料以树枝、树叶、原木、石头等低复杂度资源为主。

### 材料规则

- 材料可堆叠。
- 材料占用背包格子，同类材料在同一格内堆叠到上限。
- 材料有重量，参与负重计算。
- 材料回家后进入家园仓库，仓库内同类材料堆叠上限暂定 999。

### 材料字段补充

| 字段 | 说明 |
|-|-|
| material_tag | 木材 / 石材 / 植物 / 特殊材料 |
| region | 主要产出区域 |
| is_key_material | 是否为任务/追踪相关材料 |

## 家具

家具是家园摆放和贴纸生产的核心对象。家具可以来自宝箱，也可以由材料和蓝图通过工作台制作。

### 家具状态

| 状态 | 说明 |
|-|-|
| locked | 未获得蓝图，不可制作；可在图鉴中显示剪影或未解锁状态 |
| blueprint_unlocked | 已获得蓝图，但材料可能不足 |
| craftable | 已有蓝图且材料足够，可制作 |
| in_storage | 已制作或带回，存于仓库 |
| placed | 已摆放在家园格子中 |

### 家具字段补充

| 字段 | 说明 |
|-|-|
| furniture_id | 家具ID |
| size | 小 / 中 / 大，影响占格与重量 |
| grid_w / grid_h | 家园摆放占用格子 |
| room_type | 可摆放房间类型 |
| style_tag | 森林、温暖、照明、休息等 |
| set_id | 套装ID，可为空 |
| blueprint_id | 对应蓝图ID |
| recipe | 制作材料列表 |
| sticker_yield_base | 小动物贴纸反馈的基础产出 |
| buff_id | 特殊家具Buff，可为空 |

## 蓝图

蓝图取代旧“数值进度解锁家具”的职责。玩家需要获得蓝图，才拥有制作对应家具的权限。

### 蓝图规则

- 蓝图可以从野外宝箱、任务、家园扩建或小动物需求中获得。
- 蓝图获得后，图鉴中对应家具从 locked 变为 blueprint_unlocked。
- 已学习蓝图不重复占背包；重复获得时可转化为少量贴纸、材料或直接丢弃，具体待定。
- 蓝图不等于家具，玩家仍需材料才能制作。

### 蓝图字段

| 字段 | 说明 |
|-|-|
| blueprint_id | 蓝图ID |
| unlock_furniture_ids | 解锁的家具列表 |
| source_region | 主要来源地图 |
| unlock_condition | 是否需要扩建/任务前置 |
| duplicate_rule | 重复获得处理 |

## 特殊家具 Buff

特殊家具可提供很小的被动增益，主要作用于野外探索。它是锦上添花，不是主要能力来源。

### Buff约束

- 单件特殊家具Buff效果必须较小。
- 同类Buff必须有叠加上限。
- Buff不能替代贴纸投资的装备升级。
- UI需要标明“轻微加成”，避免玩家误以为必须堆特殊家具。

## 贴纸

贴纸是货币，不进入背包格子。贴纸由小动物根据家园状态反馈给玩家，进入货币栏。

贴纸详细规则见 [贴纸经济系统详细设计](04-3-贴纸经济系统详细设计.md)。

## 实现验收

- 程序能通过 item_id 查询物品类型、堆叠、重量、图标、描述。
- 材料能堆叠进入背包和仓库。
- 家具能在 locked / blueprint_unlocked / craftable / in_storage / placed 之间流转。
- 蓝图获得后能解锁对应家具制作权限。
- 贴纸不占背包格子，只进入经济系统。
