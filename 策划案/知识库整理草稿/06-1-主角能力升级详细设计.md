# 主角能力升级详细设计

## 系统定位

主角能力升级是贴纸投资的强路径之一。它把家园产出的贴纸转化为野外探索效率，让玩家感到“把家经营好，会让下一次冒险更强”。

## 最新口径

- 能力升级消耗贴纸。
- 能力是固定栏位，不做随机词条。
- V1只保留三个能力方向，避免旧稿中鞋子、护甲、主动技能、图腾、饰品同时存在造成系统过重。
- 每个能力都必须对野外探索产生实质影响。

## 三个能力栏位

| 栏位 | 作用 | 对应体验 | 详细文档 |
|-|-|-|-|
| 手电/光源 | 视野、续航、撤离容错 | 看得更远、撑得更久、识别目标更清楚 | [手电与光源系统详细设计](06-2-手电与光源系统详细设计.md) |
| 背包/负重 | 携带量、超重惩罚 | 能带更多东西，风险更可控 | [背包系统详细设计](04-2-背包系统详细设计.md) |
| 机动/隐匿 | 移动、逃脱、被发现压力 | 更容易撤离或脱险 | 本文下方 |

## 升级通用规则

| 字段 | 说明 |
|-|-|
| ability_id | ability_light / ability_bag / ability_mobility |
| level | 从 0 开始，V1建议最高 3 级 |
| sticker_cost | 升级消耗贴纸 |
| effect_desc | UI展示描述 |
| effect_params | 实际参数，如半径、容量、移速倍率 |
| unlock_condition | 是否需要主线、房间扩建或蓝图前置 |

## 升级流程

1. 玩家打开能力投资界面。
2. 选择一个固定能力栏位。
3. UI显示当前等级、下一级效果、贴纸消耗、是否满足条件。
4. 玩家点击升级。
5. 若贴纸足够且条件满足，扣除贴纸。
6. 播放升级反馈。
7. 参数生效。

V1建议“下次进入野外生效”，避免玩家在野外中途升级导致视野、负重、追逐状态需要动态重算。

## 背包/负重升级

| 等级 | 效果建议 | 备注 |
|-|-|-|
| 0 | 主背包 6 格，基础负重 | 初始状态 |
| 1 | 主背包 +1 格或负重惩罚轻微降低 | 第一次投资立刻有感 |
| 2 | 主背包 +1 格，超重减速降低 | 中期目标 |
| 3 | 安全背包 +1 格或负重风险明显降低 | 强力但不能取消撤离压力 |

背包格子与死亡/撤离规则见 [背包系统详细设计](04-2-背包系统详细设计.md)。

## 机动/隐匿升级

V1不建议同时做多种主动技能。可以先做一个综合栏位，表现为“更安全地移动”。

| 等级 | 效果建议 | 说明 |
|-|-|-|
| 0 | 基础移速、基础被发现压力 | 初始状态 |
| 1 | 小幅提升移动速度 | 提升探索效率 |
| 2 | 降低被发现/被追逐压力 | 具体公式待怪物重做后绑定 |
| 3 | 获得短时脱险能力或更强隐匿 | 是否做主动技能待定 |

## UI要求

- 能力界面必须显示当前贴纸数。
- 每个能力显示当前等级、下一级效果和贴纸消耗。
- 不满足条件时，按钮置灰并写明原因。
- 升级成功后显示“下次进入野外生效”或“立即生效”。

## 程序验收

- 三个固定能力栏位可读取配置。
- 贴纸足够时可升级，贴纸不足时不可升级。
- 升级后参数保存到玩家存档。
- 进入野外时按存档能力等级应用参数。
- 旧鞋子/图腾/饰品系统不作为V1能力主结构实现。
