# 家园扩建与贴纸反馈详细设计

## 系统定位

家园扩建和贴纸反馈共同构成家园侧的成长系统。玩家通过家具和小动物获得贴纸，再用贴纸扩大家园或投资能力，形成下一轮野外目标。

## 贴纸反馈触发

| 触发源 | 触发条件 | 反馈形式 |
|-|-|-|
| 单件家具 | 首次摆放关键家具 | 小动物气泡 + 少量贴纸 |
| 套装家具 | 摆放满足套装条件 | 小动物气泡 + 较多贴纸 |
| 小动物需求 | 完成明确需求 | 对话 + 贴纸奖励 + 新需求/蓝图可能出现 |
| 扩建完成 | 解锁新房间或新屋 | 新小动物/新蓝图/新需求 |

## 贴纸领取流程

1. 系统检测家具摆放或需求完成。
2. 小动物进入可反馈状态。
3. 小动物头顶出现贴纸气泡。
4. 玩家靠近并点击气泡。
5. 播放短对话或表情反馈。
6. 贴纸飞入货币栏。
7. 若满足投资条件，HUD或提示条显示“可升级/可扩建”。

## 家园扩建流程

1. 玩家打开扩建界面或靠近扩建入口。
2. UI展示扩建项：名称、预览图、贴纸消耗、附加条件、解锁内容。
3. 玩家确认扩建。
4. 扣除贴纸。
5. 播放扩建反馈。
6. 解锁新空间。
7. 同步解锁新蓝图、新小动物或新需求。
8. 新需求进入任务/追踪系统，推动下一轮野外探索。

## 扩建数据字段

| 字段 | 说明 |
|-|-|
| expansion_id | 扩建ID |
| name | 显示名 |
| sticker_cost | 贴纸消耗 |
| prerequisite | 前置条件，如主线/房间数/蓝图 |
| unlock_room_ids | 解锁房间 |
| unlock_blueprint_ids | 解锁蓝图 |
| unlock_critter_ids | 新入住小动物 |
| new_need_ids | 新需求/任务 |
| preview_asset | UI预览图 |

## UI要求

- 贴纸气泡必须能被玩家明确看到。
- 扩建界面必须展示“花贴纸后会得到什么”。
- 扩建成功后要把新蓝图/新小动物/新需求逐项提示。
- 不满足条件时，扩建按钮置灰并说明原因。

## 程序验收

- 家具摆放能触发小动物贴纸气泡。
- 点击气泡能增加贴纸并清除气泡状态。
- 扩建能消耗贴纸并保存空间解锁状态。
- 扩建能触发至少一种后续内容：蓝图、小动物或需求。
