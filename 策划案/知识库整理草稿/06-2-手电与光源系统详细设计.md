# 手电与光源系统详细设计

## 系统定位

手电/光源是野外探索的核心限制机制，也是主角三个贴纸升级能力之一。它同时承担视野、探索时长、撤离压力、目标发现和氛围营造。

## 设计目标

- 用光源控制玩家能看多远。
- 用光源续航控制单局探索时间。
- 用亮度衰减制造撤离压力。
- 用光照反馈强化“逼近资源/宝箱”的确认感。

## 基础规则

| 规则 | V1口径 |
|-|-|
| 光源随时间消耗 | 是 |
| 油量/电量越低，视野半径越小 | 是 |
| 油量耗尽前需要撤离 | 是 |
| 光源可升级 | 是，三大能力之一 |
| 光是否吸引怪物 | 待怪物重做后确认，当前只保留接口 |

## 光源状态

| 状态 | 触发 | 效果 |
|-|-|-|
| 满亮 | 进入野外时 | 标准视野半径，采集点/宝箱信号最清楚 |
| 衰减 | 随探索时间推进 | 视野半径逐步降低，边缘变暗 |
| 低亮警告 | 低于阈值 | UI警告，音效/画面提示撤离 |
| 熄灭/极低亮 | 耗尽 | 视野极小或强制撤离失败规则待定 |

## 关键参数

| 参数 | 说明 |
|-|-|
| max_energy | 最大电量/油量 |
| drain_rate | 每秒消耗 |
| radius_full | 满亮视野半径 |
| radius_min | 最低视野半径 |
| low_energy_threshold | 低亮警告阈值 |
| signal_detection_bonus | 对资源/宝箱信号的发现加成 |
| danger_exposure_factor | 光对危险暴露的影响，待怪物重做后启用 |

## 视野半径规则

建议使用曲线而不是硬切：

```text
energy_ratio = current_energy / max_energy
current_radius = radius_min + (radius_full - radius_min) * curve(energy_ratio)
```

curve 可以先用线性，后续根据体感改成缓入缓出。低亮阶段要明显可感知，避免玩家突然失去视野。

## 升级设计

| 等级 | 效果建议 | 玩家感受 |
|-|-|-|
| 0 | 基础续航、基础视野 | 只能完成短局探索 |
| 1 | 续航提升 | 能多拿一点，撤离压力降低 |
| 2 | 视野半径提升或低亮衰减变慢 | 更容易发现资源/路线 |
| 3 | 信号识别强化或紧急余光 | 更容易发现宝箱/目标，容错更高 |

## 与野外资源信号的关系

光源不只是照明，还负责让玩家感到“我正在逼近”。资源点、宝箱、地标可以在光照边缘提前露出信号：微光、轮廓、声音或UI提示。升级后可以让信号更早、更清楚或更稳定。

## 与撤离的关系

低亮警告出现后，玩家应明确知道“现在该考虑回家”。撤离方向可以由指针、地图边缘提示或家园方向光标提供。不要让玩家因为看不见路而纯粹迷路失败。

## 与怪物的关系

怪物系统当前待重做，因此光吸引怪物不作为V1硬规则落地。但代码上建议保留 danger_exposure_factor 参数，后续可接入“光越亮越容易被发现”或“零散亮光吸引危险”的设计。

## UI要求

- HUD显示光源能量条。
- 低亮时出现明显警告。
- 低亮时画面边缘变暗或光圈缩小。
- 升级界面展示下一级具体收益：续航、半径、低亮阈值或信号发现。

## 程序验收

- 光源能量随野外时间消耗。
- 视野半径随能量变化。
- 低亮阈值能触发UI提示。
- 光源等级能改变至少一个参数。
- 进入野外时按当前光源等级初始化。
- 离开野外后光源状态重置或按设计恢复。
