# 任务、叙事与小动物情感

## 系统定位

任务和小动物系统共同解决“玩家为什么为这个家投入”的问题，并承载“守护与陪伴”的核心情绪。主线负责推进流程，支线负责补充角色故事，短期心愿持续生成收集、制造和探索目标，信任、心情与共同记忆让小动物成为装修的情感锚点。

## 当前叙事目标

玩家开局需要尽快理解三件事：自己是谁、为什么要出门、为什么要把家变好。最新循环口径要求序章完成一次完整小循环：出门捡材料/蓝图 -> 回家做家具 -> 摆放家具 -> 小动物产生贴纸反馈。

## 任务分类

| 类型 | 作用 | 是否阻塞主线 |
|-|-|-|
| 长期主线 | 贯穿流程、推进章节、教学核心循环 | 是 |
| 中期支线 | 小动物阶段性委托、个人故事与关系发展 | 否 |
| 短期心愿 | 持续提供收集、制造、装修、探索目标，并消耗多余物资 | 否 |
| 情感任务 | 心情、信任、突发需求 | 否 |

支线和情感任务不应阻塞主线，只提供额外内容、奖励和陪伴感。

## 主线任务

主线的首要任务是教学双循环，而不是讲完世界观。建议前 15 分钟围绕一个小动物需求展开：小动物没有舒适住处，玩家出门寻找材料，回家制作并摆放第一件关键家具，小动物表达感谢或产生新的愿望。

章节结构统一采用“野外探索 -> 救助/结识新动物 -> 回家建设 -> 角色反馈 -> 新阶段目标”。每增加一只动物，就自然带出一段个人故事、一批家具和一个探索目标；阶段结尾以家园扩建、角色入住或关系推进形成情绪回报，并预告下一阶段。

## 小动物系统

小动物的主要价值：

- 对玩家装修做出反馈。
- 通过对话和日记建立陪伴感。
- 通过愿望、心情和信任制造中短期目标。
- 通过家具互动展示“家变好了”。
- 记住玩家带回了什么、怎样布置房间、有没有平安回家，并在以后主动引用这些共同经历。

旧稿中“小动物每日固定产出资源”的方向已降权。小动物应是情感对象，不应被设计成资源机器。

## 信任系统

每个小动物有独立信任值。信任值来自对话、送礼、完成突发任务和阶段剧情。信任阶段影响对话深度、故事暴露、房间扩建、纪念奖励或特殊家具。

旧稿示例：对话 +8%，送礼 +20%，完成突发任务 +15%。这些数值仅作为测试参考，最终应按游戏节奏调整。

## 心情系统

小动物会拥有当前心情，可通过日记、表情、语气变化表现。心情可分为正常、不开心、开心。不开心时可触发限时突发任务；玩家完成后小动物转为开心并提升信任。

心情系统的重点不是惩罚玩家，而是制造“我注意到了它”的情感互动。

## 小动物对装修的反馈

反馈应分层：

1. 即时短反馈：玩家制造或摆放家具后，小动物给出一句短反应。
2. 房间评价：根据风格、成套家具、特定家具和小动物需求完成度给出整体评价。
3. 行为反馈：小动物使用椅子、床、花瓶等家具。
4. 长期反馈：日记记录共同经历，信任提升后讲述更多背景故事并解锁个人心愿。

## AI能力边界

AI用于解决“固定台词重复后陪伴感迅速消失”的具体问题，而不是把自由聊天本身当卖点。系统可记录玩家带回的物品、房间布置、重要互动与平安归来等事件，压缩为每只小动物的个人记忆与日记，再用于差异化回应、关系阶段故事和心愿。这样每位玩家获得的是基于真实游戏行为的独特陪伴。

生成内容必须服从剧情、世界观、角色人格和安全边界；关键章节、奖励与系统状态仍由策划和确定性逻辑控制。AI不能虚构玩家未经历的事件，也不能绕过任务条件发放奖励。

## 叙事卖点

3.31 讨论中确认，项目优势不应理解为纯装修，而是“休闲化搜打撤 + 装修模拟经营”、末世微恐与温暖家园的反差、沉浸式共同生活，以及AI小动物的个性化记忆。所有亮点最终共同服务于“守护与陪伴”。

## 长线内容

- 新地图提供新的搜打撤路线、资源、危险与世界线索。
- 新角色入住带来个人故事、心愿、专属家具和新的家园空间。
- 新家具主题与季节活动同时提供装修表达、经营消耗和野外目标。
- 新内容必须回到既有双循环，避免形成与家园、角色无关的孤立活动。

## 待定问题

- 开头剧情文本和第一只小动物的具体角色弧光。
- 小动物愿望是否直接生成家具追踪目标。
- 信任值奖励是照片、家具、房间扩建还是剧情片段。
- AI对话采用模板、检索增强还是生成式混合。
