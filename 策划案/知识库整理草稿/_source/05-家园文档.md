# 系统定位

1.1 在整体游戏中的位置

        •        野外探索：资源获取 + 张力调味

        •        家园系统：情感核心 + 成长反馈 + 主循环承载

家园系统为主舞台



# 核心设计目标

## 情绪目标

        •        野外带来轻度紧张

        •        回到家园获得安全、治愈、成就感

## 行为目标

鼓励玩家：

        •        经常回家

        •        反复装修、替换家具

        •        主动和小动物对话

        •        期待下一个剧情解锁

## 节奏目标

        •        单局流程（Demo）：约 40 分钟

        •        家园操作占比 ≥ 45%



# 家园空间结构

## 总体结构

        •        家园为一个连续、无加载的整体空间

        •        玩家以 WASD 控制瓢虫在家园中自由移动（无交互）

## 空间组成：

1.  小动物独立房间
2. 一个较安全的、空旷的室外

## 房间类型定义



①  小动物房间

        •        每个小动物拥有独立房间

        •        房间风格与其性格、剧情强相关

        •        随着信任度提升：

                      房间扩建

                      家具摆放上限增加

                      家人出现

⸻

② 室外

功能：

        •        连结室内安全与室外危险的区域（类似鸭科夫刚出野外的那块安全区域）

# 玩家在家园中的两种模式

## 行走模式

        •        WASD 控制瓢虫移动

        •        摄像机近景跟随

        •        可：

                      靠近 NPC 对话

                      走到工作台交互（？）

                      放大缩小观察装修细节（？）

用途：

        •        情感沉浸

        •        空间感建立



⸻



##  装修模式

        •        由按键 切换

        •        摄像机拉远，展示当前房间全貌

        •        同步出现仓库界面 -- 由UI设计

        •        玩家角色静止

        •        家具以网格方式摆放



用途：

        •        精确摆放

        •        高效装修

        •        系统性操作





# 家具系统

## 5家具分级

| 等级 | 获取方式 | 定位 |
|-|-|-|
| 初级 | 野外宝箱 | 教学 |
| 中级 | 工作台合成 / 野外宝箱 | 风格化设计 |
| 高级 | 中级升级 | 成就感 / 剧情门槛 |
| 装饰物 | 野外宝箱 / 事件 | 风格化设计 / 收集感 |
| 特殊  | 特殊事件  | 记忆点 / 情感链接 |

⸻



##  数量规划（40 分钟 Demo）

        •        初级：6 件

        •        中级：10 件

        •        高级：16 件

        •        装饰物 3 件

        •        特殊：2 件



⸻



## 家具属性



每件家具至少包含：

        •        风格标签（未定 -- 等待美术确认）

        •        NPC 偏好标签

        •        负重值

        •        合成 / 升级关系



⸻



## 合成规则（简化）

        •        2 个同级家具 + 1个装饰物 → 1 个高一级家具

        •        配饰 - **3 个中级配饰** → **1 个高级配饰**

        •        高一级家具风格根据装饰物确定



⸻



# 仓库

        •        用于存放玩家所有收集物品

        •        仓库界面除按键显示外，还会在合成台、装修模式喜下同步出现  -- 界面由UI设计



# 工作台系统

## 解锁方式

        •        通过剧情（水獭妹妹出现）解锁



## 功能

        •        中级 /  高级家具合成

        •        查看已解锁配方

        •        合成后直接进入背包



⸻



# NPC 与信任系统

        •        小动物的信任值依靠对话和送礼增长 - 达到一定阶段会解锁任务

        •        与任务系统强绑定

        •        具体细节看任务文档





# 安全与规则边界

     •        家园为绝对安全区

     •        敌人不会进入 / 出现在家园

     •        家园中不产生失败惩罚





# 家园系统的核心循环

探索 → 获取家具 / 材料

   ↓

回到家园

   ↓

装修 / 合成 / 对话

   ↓

信任提升 & 剧情解锁

   ↓

房间扩建 / 新目标





# 设计原则总结

    •        家园是情感中心，不是操作负担

    •        家具是表达关系的媒介

    •        装修是过程乐趣，而非评分系统

    •        系统复杂度永远让位于情绪体验
