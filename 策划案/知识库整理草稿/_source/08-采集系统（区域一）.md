# 一、设计目标

### 核心定位

区域1 = **安全区 / 教学区 / 正反馈区**

### 设计目的

1. **让玩家理解基础循环**

   <callout emoji="🥛">
    接任务 → 出门 → 采集 → 回家 → 制作 
   </callout>
2. **建立“采集是有回报的”正反馈**

   -  不强调压力、不强调失败 
3. **为后续区域做认知铺垫**

   -  提前让玩家熟悉： 
   
     -  材料类型 
     -  背包概念 
     -  基础路径探索

## 2.3 刷新规则

### 方案（一）

-  节点被采集后： 

  - **30秒后刷新**
  -  或**离开区域后刷新**

#### 节点状态：

存在 → 被采集 → 冷却 → 刷新

👉 目的：

-  保证资源稳定 
-  避免玩家“被卡住” 
- 针对轻度（手残）玩家，可以通过等待/先探索其他区域刷新

👉 问题：

-  玩家会不会不会向深处探索了一直待在原地等待刷新

### 方案（二）

-  节点被采集后： 

  - **不会刷新**

#### 节点状态：

存在 → 被采集 → 继续向深处寻找更多材料

👉 目的：

-  通过控制玩家手里的材料，迫使他们不断继续向深处探索

👉 问题：

-  不能保证资源稳定，玩家可能会因为缺少资源被卡住？ → 有一个类似商城或其他可以兑换物品的系统

# 四、关卡布局设计

##  设计原则

### ✅ 原则1：资源明显

-  所有资源节点必须**明显可见**
-  与不可采集物区分来来

---

### ✅ 原则2：路径“自然引导”

-  用： 

  -  小路 
  -  光照 
  -  地形开口 

👉 引导玩家走到资源点

---

### ✅ 原则3：轻探索感

-  区域有**2–3条分支**
-  每条分支都能拿到资源 

👉 给玩家“我在探索”的感觉，但不会迷路

---
