# 工作台与图鉴UI详细设计

## 系统定位

工作台与图鉴UI是家园内最重要的操作入口，负责家具浏览、蓝图状态、制造/分解、仓库摆放、家具追踪和装修编辑模式。

## 入口

- 按 B 键进入。
- 点击常驻UI中的工作台/册子图标进入。
- 不要求玩家走到场景中的工作台实体才能进入。

## 打开后的状态

1. 打开工作台/图鉴界面。
2. 强制进入装修（编辑）模式。
3. 同时展示图鉴区域和仓库区域。
4. 关闭界面后退出装修（编辑）模式。

## 主界面结构

| 区域 | 内容 |
|-|-|
| 左侧分类 | 全部、家具、墙饰、摆件、地饰、装修、材料等 |
| 中央图鉴 | 家具卡片、蓝图状态、可制作状态、套装信息 |
| 右侧详情/弹窗 | 制造、分解、追踪、材料需求 |
| 下方仓库 | 已拥有家具、材料、装修类物品 |
| 场景层 | 当前房间网格和已摆放家具 |

## 家具卡片状态

| 状态 | 显示 |
|-|-|
| 未解锁 | 剪影或灰卡，可显示来源提示 |
| 蓝图已获得 | 正常显示，标记“蓝图已获得” |
| 材料不足 | 显示缺少材料数量 |
| 可制作 | 显示制作按钮或高亮 |
| 仓库已有 | 右下角显示拥有数量 |
| 已追踪 | 显示追踪标记 |
| 新获得 | 分类Tab和卡片红点 |

## 制造弹窗

点击图鉴内家具 icon 后，弹出制造/分解/追踪界面。

弹窗内容：

- 家具图标和名称。
- 当前拥有数量。
- 所需材料图标、数量、当前仓库数量。
- 蓝图状态。
- 制作按钮。
- 分解按钮。
- 追踪按钮。

## 制作流程

1. 玩家点击家具卡片。
2. 弹出制造弹窗。
3. 系统检查蓝图和材料。
4. 若可制作，制作按钮可点击。
5. 点击制作，扣除材料。
6. 家具进入仓库并排到仓库最前。
7. 可选择直接进入摆放。

## 分解流程

1. 玩家在仓库或弹窗中选择已有家具。
2. 点击分解。
3. UI展示返还材料。
4. 玩家确认。
5. 家具数量减少，材料进入仓库。

## 追踪流程

1. 玩家点击追踪按钮。
2. 若追踪数量未满，家具进入追踪列表。
3. 暂定最多追踪 3 个家具。
4. 每个家具最多展示 4 种材料需求。
5. 被追踪家具在图鉴中置顶或高亮。
6. 野外HUD显示追踪材料缺口。

## 仓库交互

- 仓库中已有家具显示数量。
- 新制造家具自动放到家具栏最前。
- 仓库中的家具可以直接拖到场景中摆放。
- 仓库分为家具、材料、装修三栏；装修包括墙纸、地板、斜天花板等。

## 编辑模式

- 进入界面后自动显示当前房间网格。
- 点击场景内家具弹出个体交互按钮。
- 长按或选中家具进入编辑状态。
- 显示格子名称，名称控制在 6 字以内。
- 支持拖动、旋转、回收、确认摆放。
- 旋转按钮图标不能像刷新。

## 程序验收

- B键和UI图标都能打开工作台/图鉴界面。
- 打开后进入装修编辑模式，关闭后退出。
- 家具卡片能正确显示蓝图、材料、拥有数量、追踪、新获得状态。
- 制作能扣材料并生成家具。
- 分解能扣家具并返还材料。
- 追踪最多 3 个家具，并能在野外HUD读取。
- 仓库家具可拖拽到场景中摆放。
