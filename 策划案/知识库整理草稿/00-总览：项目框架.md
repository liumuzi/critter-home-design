# 总览：项目框架

## 一句话定位

《虫虫装修》是一款以“休闲化搜打撤 × 装修模拟经营”为核心双循环的休闲冒险游戏。玩家扮演一只小小的瓢虫，在人类消失后的末世森林中搜索废墟、取舍物资、躲避寄生植物侵袭的危险并成功撤离，再把带回家的资源转化为家具、经营收益、小动物反馈、能力投资和新的探索目标。

项目不是把两个玩法简单拼接：野外保留“越贪越危险，带走才算赢”的搜打撤决策，通过短局、非硬核战斗和较低操作门槛完成休闲化；家园以装修作为经营行为，通过制造、摆放、住户需求和扩建形成模拟经营循环。

## 核心体验

游戏追求“一张一弛”的持续心流，并以“守护与陪伴”为核心情绪：野外提供微恐、目标感和风险决策；家园提供安全、治愈、装修经营和情感反馈。因为野外危险，家园才显得温暖；因为小动物在家中生活、回应并记住玩家，冒险与装修才有意义。

## 目标玩家

- 核心目标：18-25 岁、偏好二次元审美与休闲治愈游戏的年轻女性玩家。
- 喜欢装修、模拟经营、收集和空间布置的玩家。
- 喜欢轻度冒险、搜集资源和短局决策的玩家。
- 喜欢小动物、情感陪伴、角色反馈和虚拟生活氛围的玩家。
- 喜欢“探索 + 模拟经营”组合，但认为纯经营偏平淡、硬核搜打撤门槛过高的玩家。

## 设计来源与差异化

项目从《潜水员戴夫》的“冒险 + 经营”双循环获得结构灵感，也从搜打撤产品的基地建设中看到扩展机会：把基地建设深化为装修与模拟经营，让每次撤离都能在可见空间、住户生活和长期成长中兑现。差异化组合由四部分构成：

1. 休闲化搜打撤：保留搜索、风险取舍与撤离，降低战斗和操作门槛。
2. 装修模拟经营：装修既是自由表达，也是经营收益与成长投资的来源。
3. 末世微恐 × 温暖家园：危险与安全形成稳定的情绪切换。
4. AI小动物记忆：让角色基于真实共同经历回应玩家，强化守护与陪伴。

## 核心循环

```text
看到需求 / 追踪家具 / 明确缺口
  -> 出门探索
  -> 采集材料、蓝图、家具、饰品
  -> 背包取舍与撤离
  -> 回家结算入仓
  -> 工作台制造 / 图鉴追踪 / 装修摆放
  -> 小动物贴纸反馈 / 新蓝图解锁 / 新需求出现
  -> 贴纸投资能力或家园扩建
  -> 生成下一轮缺口
```

这个循环的重点不是“野外好玩”和“家园好看”分别成立，而是两者互相制造需求、反馈和下一步目标。

## 当前设计原则

1. 节奏优先：野外紧张、家园放松，任何一端拖太久都会削弱心流。
2. 目标可见：玩家出门前要知道缺什么，回家后要知道推进了什么。
3. 回家即兑现：撤离、入仓、制造、摆放、小动物贴纸反馈应形成连续奖励链。
4. 情感增益：小动物负责让装修“有意义”，不应变成纯数值产出机器。
5. 温和挑战：野外需要压力和损失，但不能把休闲装修玩家劝退。
6. 系统克制：Demo阶段优先跑通双循环，不把所有高级系统一次性展开。
7. 守护一致：世界观、风险、装修、经营与AI反馈都应强化“我在为它们创造安全生活”的感受。

## 内容与长线结构

- 长期主线按“野外救助/结识 -> 回家建设 -> 角色反馈 -> 新阶段目标”推进，每只新动物自然带出故事、家具和探索目标。
- 中期支线承载小动物个人故事；短期心愿持续提供收集、制造、装修和探索缺口。
- 新地图、新角色、新家具主题与季节活动均应接回同一双循环，避免形成彼此孤立的活动玩法。
- 装修成果和AI生成的个性化共同回忆具有分享价值，社区内容以晒家、角色故事和主题活动为主要载体。

## Demo体验目标

- 玩家在前 10-15 分钟内理解“冒险是为了让家变好”。
- 玩家至少完成一次：接到明确需求 -> 出门找材料/蓝图 -> 回家制造 -> 摆放 -> 获得小动物贴纸反馈。
- 玩家在第一次完整循环结束后能看到下一目标：下一件家具、下一次能力投资、下一处家园扩建、下一张地图或下一段剧情。
