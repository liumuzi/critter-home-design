# 总览：项目框架

## 一句话定位

《虫虫装修》是一款以“野外探索 × 家园装修”为核心双循环的休闲冒险游戏。玩家扮演一只乐于助人的瓢虫，在森林中探索、采集、躲避危险，把带回家的资源转化为家具、小动物贴纸反馈、能力投资和新的探索目标。

## 核心体验

游戏追求“一张一弛”的持续心流：野外提供轻度紧张、目标感和风险决策；家园提供安全、治愈、装修满足和情感反馈。两端不能割裂，玩家每次出门都应知道自己为了什么而冒险，每次回家都应感到这趟冒险被兑现。

## 目标玩家

- 喜欢装修、收集和空间布置的玩家。
- 喜欢轻度冒险、搜集资源和短局决策的玩家。
- 喜欢小动物、情感陪伴、角色反馈和虚拟生活氛围的玩家。

## 核心循环

```text
看到需求 / 追踪家具 / 明确缺口
  -> 出门探索
  -> 采集材料、蓝图、家具、饰品
  -> 背包取舍与撤离
  -> 回家结算入仓
  -> 工作台制造 / 图鉴追踪 / 装修摆放
  -> 小动物贴纸反馈 / 新蓝图解锁 / 新需求出现
  -> 贴纸投资能力或家园扩建
  -> 生成下一轮缺口
```

这个循环的重点不是“野外好玩”和“家园好看”分别成立，而是两者互相制造需求、反馈和下一步目标。

## 当前设计原则

1. 节奏优先：野外紧张、家园放松，任何一端拖太久都会削弱心流。
2. 目标可见：玩家出门前要知道缺什么，回家后要知道推进了什么。
3. 回家即兑现：撤离、入仓、制造、摆放、小动物贴纸反馈应形成连续奖励链。
4. 情感增益：小动物负责让装修“有意义”，不应变成纯数值产出机器。
5. 温和挑战：野外需要压力和损失，但不能把休闲装修玩家劝退。
6. 系统克制：Demo阶段优先跑通双循环，不把所有高级系统一次性展开。

## Demo体验目标

- 玩家在前 10-15 分钟内理解“冒险是为了让家变好”。
- 玩家至少完成一次：接到明确需求 -> 出门找材料/蓝图 -> 回家制造 -> 摆放 -> 获得小动物贴纸反馈。
- 玩家在第一次完整循环结束后能看到下一目标：下一件家具、下一次能力投资、下一处家园扩建、下一张地图或下一段剧情。
