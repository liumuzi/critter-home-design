# 日常对话 - 和玩家记忆的反馈

这个对话的功能，我们会给 AI 输入以下内容：

1. 家具的摆放
2. 主线任务的完成程度
3. 动物当天的心情和状态
4. 根据玩家的最近的行为问候玩家

   - 不定时 / 它自己觉得很有记忆点的瞬间产生对话
5. 小动物会各自有对玩家的认知、情感和记忆，在对话和行为中体现
6. 小动物间的社区 - 串门 、打架（页面边缘会有小动物行为icon） 、聊天（八卦） 

# 请求帮助

1. 索要物品向玩家
2. 请求玩家帮忙收集某件物品
3. 如果玩家拒绝这些帮助，小动物就会一直嚎叫生气

# 记忆

1. 包含它和玩家之前发生过的一些事情
2. 它自己觉得很有记忆点的瞬间（比如玩家第一次xxx）
3. 对玩家的认知、情感以及对话交流

# 任务（信任）

## 信任线

日常行为 / 对话

## 支线

信任  -  动物剧情（背景故事开放程度）  → 小动物的背景故事故事 -- 1到3条固定的参考

达到一定阶段开始 -- CG或文本形式

## 主线任务

引入阶段 （水獭一家）

新的小的小动物引入+放假的开辟 → 玩家和小动物后续的故事 → 真实的世界



剧情的展开 ： 主线全部固定+小动物剧情体现

/ 故事的回顾

# 信件（旅行青蛙）

小动物可以出门旅游，途中会给玩家寄来信件和照片。用AI生成照片风景，然后把小动物的图贴上去。AI生成信件内容

根据文本随机生成小的物件 - 小花

# 送礼

1. 根据小动物与玩家的对话情况，小动物会自动判断玩家~~今天~~的愿望和需求，当AI觉得发现玩家愿望时，赠送玩家一个他认为玩家想要的礼物

# 行为互动

1. 小动物会一直关注玩家，跟随玩家移动
2. 玩家从野外回来，小动物会在门口等待迎接
3. 玩家大装修一次，小动物会全部赶来鼓掌
4. 小动物想念玩家了，就会来玩家的家里玩，睡觉

# 心情日记

小动物每天会在日记里标记当天心情，如果和玩家之间有发生什么值得记录的事情，也会记录在日记里
