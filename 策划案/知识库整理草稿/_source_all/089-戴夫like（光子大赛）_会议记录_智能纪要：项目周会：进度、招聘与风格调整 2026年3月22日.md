# 总结

<whiteboard token="Qir6w1nfkhBJ9pbumJGcBf02n3d"></whiteboard>

本次会议是项目的每周例会，各成员汇报工作进度，讨论了人员招聘、美术风格调整、任务分配等问题，明确了后续工作方向和时间节点，内容如下：

- **工作进度汇报**

  - **佩玖**：本周梳理了整体框架，正在进行采集和经济系统的策划案制作，预计完成后工作台部分可很快完成，尽量赶在下周末。
  - **刘木子**：正在制作小动物原型，已将网址发在群里供大家体验。目前对修改方向感到迷茫，设想玩家装修时小动物能有动作和表情反馈，但测试效果不佳。
  - **粥粥**
  
    - 素材拼接：将大家的素材拼了野外场景并涂色，建议后续不用之前的底色。厨房部分发现徐老师画的指纹纹路在家具中较突兀，但家具适配房间。
    - 素材调整：手头上的素材多为冬季风格，后续尝试调整为春季风格。雪格和咸水鱼已上传树叶和春天花草素材，粥粥晚上再进行拼接。
  - **咸水鱼**
  
    - 角色设计：改完主角形象并画三视图，不确定是否负责角色动画。考虑到动画需求多，建议招聘动画老师统一制作。
    - 人设修改：重新修改姐姐和妹妹人设并发送到群里，确定水獭一家后可细化。
  - **雪格**
  
    - 房间设计：设计妹妹房间并画草图，用茶壶做炉子的设计获好评。考虑参考奇妙仙子在 Pinterest 上的参考图。
    - 颜色调整：咸水鱼建议家具颜色用浅原木色，雪格将参考橘子老师的颜色进行调整。
  - **suki**
  
    - UI 修改：修改 UI 并重新找字体，将老师们的素材放入，按等比缩小 icon。认为目前 icon 可先使用，让大家聚焦其他工作。
    - UI 调整：程浩建议野外氛围暗一些，背包描边暗一些，suki 表示先尝试调整描边，后续根据整体效果再做调整。背包默认位置改到右边。
  - **程浩**
  
    - 系统任务进度：检查上周野外系统任务拆分进度，程序部分基本完成，美术部分家园场景外围搭建完成，躲藏点资产粥粥已做完待上传，贴图和迷雾暂不做，可考虑用云朵代替。
    - 下周任务分配：下周野外系统开发主要由润飞老师负责，程浩周三与润飞老师确认工作内容。美术老师需提供怪物模型设计，动画部分等招聘到动画老师后再做。
    - 家园系统梳理：梳理家园建造系统思维导图，与主策沟通补充策划任务。程序任务因刘木子没时间暂时搁置，美术任务主要是 UI 设计，明天与付伟老师细聊。

- **人员安排与招聘**

  - **动画老师招聘**
  
    - 招聘原因：因动画需求多，目前没有专门的动画老师，且橘子老师 28 号有考试，时间紧张，决定尽快招聘动画老师。
    - 招聘方式：通过小红书账号发布招聘需求，同时自行发帖，以加快招聘速度。
  - **怪物设计安排**
  
    - 雪格参与：雪格表示下下周天可能有时间画怪物设计，先完成房子绘制。
    - 咸水鱼备用：咸水鱼若画完角色也可参与怪物设计。
- **美术风格调整**
