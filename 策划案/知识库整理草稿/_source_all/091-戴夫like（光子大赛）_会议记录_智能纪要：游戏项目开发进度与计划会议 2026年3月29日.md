- **项目进度汇报**

  - **佩玖**：完成采集和工作台的策划案。
  - **刘木子**：仍在进行小动物相关工作，但本周较忙，暂无成果展示。
  - **粥粥**
  
    - 工作成果：完成雪格老师小房间的绘制，还有一两个家具未完成，今日可提交；对橘子老师之前画的初始房间家具进行细化。
    - 素材运用：尝试使用 Pinterest 上的素材丰富画面效果。
  - **雪格**
  
    - 工作成果：完成所有户外素材，等待咸水鱼老师的荧光植物素材后进行拼接。
    - 下周目标：完成地标拼接并上传至飞书。
  - **suki**
  
    - 工作进展：与策划梳理工作台细节，基本完成绘制，待与策划核对后共享。
    - UI 设计：对工作台 UI 进行布局调整，考虑操作逻辑优化弹窗位置；制作材料追踪功能和任务系统；完成图鉴、工作台和仓库的弹窗设计。
  - **程浩**：本周主要忙于开会，无实体进度。
  - **虞润飞**：完成野外怪物系统和光影系统的基础搭建，并在美术群分享相关效果。
  - **高高（新动画师）**
  
    - 初步评估：认为大家工作成果良好，动画制作无问题，需确定角色动作需求。
    - 角色设计讨论：与雪格等讨论角色手部设计，根据动画需求可添加；提出角色可能需要行走、冲刺、跑、飞行、跳跃等动作，需结合角色个性确定。
- **系统功能讨论**

  - **家园系统**
  
    - 核心定位：程浩提出开发核心是教研系统，家园是核心，野外是补充，目前家园系统功能寡淡，需增加设计使其更有趣。
    - 乐趣性方案：大家讨论通过增加经济系统、建造小游戏、丰富小动物交互等方式补足家园乐趣性；刘木子认为应做好反馈机制；虞润飞建议下周专注家园系统，完善家具摆放的美观和趣味性。
    - 开发方向：确定先将家园系统做成类似《我的休闲时光》的效果，后续再优化改进；策划需进行调研、效果拆解分析、明确分工，美术老师大规模产出教研资源，程序老师配合打通家园系统。
  - **野外系统**
  
    - 完成度考量：虞润飞认为野外系统完成度仅 20% - 30%，与可玩状态差距较大；刘木子提出在保证家园系统打磨好的前提下，缩小野外系统内容体量，将现有素材和机制放进去，作为副玩法跑通即可。
    - 参考案例：雪格以《元气骑士》为例说明简单玩法也可吸引玩家，但虞润飞指出其背后设计复杂。
- **美术资源相关**

  - **家具制作**
  
    - 人员安排：刘木子提出粥粥一人制作家具可能来不及，建议雪格老师本周先拼一些简单的野外素材，周三交付，下半周和咸水鱼老师一起协助粥粥老师制作家具。
    - 数量确定：雪格提出需确定本月内家园资源套间数量，程浩表示需策划调研竞品后确定。
  - **旋转素材**：虞润飞提出旋转功能最好有新素材，如椅子需考虑四个朝向；雪格指出部分装修游戏可偷懒，如沙发只做镜面翻转；程浩建议策划调研确定是否需要四项素材及翻转设计。
  - **玩家需求**：作为深度玩家，认为玩家重视游戏自由度，希望物品能以多种方式叠放，可自由调整图层前后关系，建议策划与雪格进一步调研收集反馈。
- **后续工作计划**

  - **策划工作**
  
    - 调研：对竞品进行调研，确定家园系统合适的家具套间数量，分析玩法提升丰富度的地方。
    - 效果拆解分析：对各种效果进行拆解分析，提出交互模式需求，并作为半个 PM 进行分工和任务分发。
    - 兼顾野外：在推进家园系统的同时，兼顾野外系统的落地，考虑继续推进目前方案或进行简化。
  - **美术工作**
  
    - 大规模产出：美术老师大规模产出教研资源，粥粥负责室内房间和家具绘制，雪格本周先完成简单野外素材拼接，周三交付，下半周协助制作家具，咸水鱼老师也参与家具制作。
    - 素材调研：参考《我的休闲时光》《造景贴纸》《冬日小老鼠》等游戏，收集素材和设计方案。
  - **程序工作**
  
    - 家园打通：木子和润飞配合打通家园系统，重点处理旋转功能和素材替换，确保素材铺入和反馈机制的实现。
    - 沟通协调：suki 与虞润飞对接 UI 进引擎的事情，确保尺寸和层级一致。
