# 合成台详细说明

## 合成台（Workbench）概述

合成台是**家园系统中的关键功能**，它允许玩家将**原材料**（如家具和装饰物）组合成**更高级的家具**，或者将不再需要的物品转换成其他有用的物品。通过合成，玩家不仅能够**改善家园环境**，还可以**解锁更多的家具选项**，并进一步推动与NPC的信任进程。

### 1.1 合成台的主要功能

- **合成物品**：允许玩家将**初级家具**或**收集物品**合成成**中级或高级家具**。
- **家具升级**：通过合成和资源管理，家具可以被逐步升级，获得新的功能或更高的美观度。
- **任务触发**：某些合成物品可能与NPC的任务挂钩，或者某个特定的家具可能解锁新的剧情内容。

---

## 合成台数据结构

合成台的功能主要依赖于**物品配方、家具 / 配饰、以及UI显示**。以下是该部分涉及的数据结构设计。

### 2.1 家具配方表（Recipe）

每种家具和装饰品都有一个对应的合成配方，玩家通过将合适的物品组合起来，才能制作出更高级的家具。以下是配方的设计：

```JSON
{
  "furnitureID": "advanced_bed",
  "name": "高级床",
  "requiredItems": [
    {"itemID": "wooden_bed", "quantity": 2},
    {"itemID": "luxury_cushion", "quantity": 1}  // luxury_cushion为装饰物代称
}
  ],
  "outputItem": {"itemID": "luxury_bed", "quantity": 1},
  "category": "家具",
  "unlockCondition": "完成主线任务2"   // 可选，是否依赖信任或剧情解锁
}
```

#### 配方字段说明：

- **furnitureID**：合成家具的ID。
- **requiredItems**：配方中所需的原料和数量。
- **outputItem**：合成后的物品ID和数量。
- **category**：家具类别（例如：床、桌子、装饰品等）。
- **unlockCondition**：解锁条件，例如NPC的信任值达到一定数值才可以解锁配方。

---

### 2.2 合成台数据（Workbench）

合成台的数据包含当前可合成的家具配方、已解锁的配方、玩家在合成台的操作状态等。

---

### 2.3 配饰合成

配饰 - **3 个中级配饰** → **1 个高级配饰**

---

## 合成台的交互流程

### 3.1 合成台的操作流程

1. **选择配方**：玩家在家园内的合成台前 / 按合成台快捷键，选择一个配方进行合成。界面将显示该配方所需的物品和数量。
2. **检查物品**：玩家点击“合成”后，系统会验证玩家背包是否拥有足够的物品。如果不够，ICON显示为灰色
3. **开始合成**：当所有物品满足要求时，玩家可以点击“开始合成”按钮，系统进入合成状态
4. **完成合成**：合成完成后，玩家将获得新家具，输出的物品将加入玩家背包
5. **任务触发**：完成合成后，系统检查该物品是否与 NPC 任务相关联，若是，触发相应的任务或剧情。

---

### 3.2 合成台UI设计

合成台的UI需要清晰地展示：

- 可选配方（玩家能合成的家具列表）
- 当前配方所需物品和数量（显示在UI中，供玩家参考）
- 合成按钮（启用条件：满足物品要求）
- 合成进度条（显示合成过程中进度）

---

## 可选功能与后续优化

### 5.1 合成台多种功能

- 合成台可以扩展更多功能，例如：**批量合成、快速合成**、或是 **合成失败系统**（例如失败会产生随机低级物品）。

### 5.2 多人合作功能（可选）

- 如果考虑到多人模式，可以将合成台的操作**同步到所有玩家的界面**，支持多人合作进行家园建设。

---

## 总结与注意事项

1. **核心设计原则**：合成台必须简洁高效，所有的合成过程和任务系统必须确保不影响玩家的主线体验。
2. **UI与交互**：用户交互应尽量直观，避免复杂的多步骤操作，配方选择和物品合成应清晰明确。
3. **功能扩展**：随着游戏的推进，可以在合成台中加入更多高级配方、特殊任务或挑战，逐步丰富系统内容。
