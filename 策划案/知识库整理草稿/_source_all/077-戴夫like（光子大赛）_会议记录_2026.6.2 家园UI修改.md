# 2026.6.2 家园UI修改

会议讨论了游戏中家具追踪功能及UI设计的相关问题，包括追踪功能的实现、UI界面的优化、图鉴与工作台的逻辑以及分类排序等，具体如下：

- **家具追踪功能**：

  - **追踪方式**：可按家具整体追踪，点击家具追踪后显示配方及仓库材料数量，让玩家自行计算。
  - **追踪上限**：暂定可追踪3个家具。一个配方最多4种材料。
  - **材料整合**：对于追踪多个家具时材料的整合方式待确定，可考虑整合或分开列。
- **图鉴与工作台设计**：

  - **图鉴形式**：做成类似书或本子的中央大图鉴，展示套装及具体家具，支持追踪和制作功能。
  - **排序方式**：图鉴按套装排，制作时按种类排，新解锁可制作的加红点；后续可添加多种排序方式供玩家手动选择。
  - **显示逻辑**：工作台只显示已解锁配方的家具，未解锁的放图鉴；图鉴和工作台的图鉴逻辑分开。
- **UI界面优化**：

  - **编辑模式**：长按家具可进入编辑模式，编辑模式显示格子，格子加名字，名字字数控制在6个以内，居中放置。
  - **仓库与菜单**：仓库和菜单用同样分类，工作台情况下，仓库展示未放的家具，点击可进入摆放；分解键从仓库或下面栏点出。
  - **图标修改**：旋转按钮图标需修改，避免像刷新。
- **其他事项**：

  - **美术风格**：目前UI与场景美术风格不太一致，先关注功能，美术问题后续再处理。
- **任务**

  - **追踪功能制作**：按照 4 种、3 个的标准制作追踪功能，思考如何方便用户操作，如使用标签切换或点击等方式，设计时避免过长，先做追踪并修改图鉴 UI 
  - **图鉴 UI 设计**：重新设计图鉴 UI，包括工作台和图鉴展示。 
  - **格子标签添加**：给所有格子添加名字标签，名字控制在 6 个字以内，可放在格子外面并适当拉开间距 
  - **工作台改与加**：将界面改成工作台，让玩家知道点里面的东西可制作；按侧边栏分类逻辑，给工作台添加几个 Tab
  - **总结内容分享**：将会议中提到的需要修改的内容总结发至群里，供说话人 2 查看是否贴到飞书中
