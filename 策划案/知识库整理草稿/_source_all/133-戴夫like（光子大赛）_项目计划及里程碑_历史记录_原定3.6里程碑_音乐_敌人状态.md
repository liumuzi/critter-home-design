# 敌人追击模式：

进入listening → 发现玩家 → 警戒状态（等待2s）→ 开始追追逐 → 追丢玩家（暂定最长持续追逐时间为6s）

## 进入listening → 发现玩家 ：

当玩家进入敌人听力范围，会立刻被观察到（发现玩家）

##  追丢玩家

敌人自动放弃追逐玩家依靠时间进行判断，**暂定**时间为6s

这个需要依靠关卡搭建完毕后的测试后续进行修改
