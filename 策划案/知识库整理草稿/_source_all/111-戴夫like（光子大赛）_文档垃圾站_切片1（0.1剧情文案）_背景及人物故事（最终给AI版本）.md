# 背景剧情

人类的足迹早已经消散在风里，世界停在了没有喧嚣的瞬间 -- 他们消失了，就像晨雾在阳光下蒸发 -- 悄无声息的消失了，没有人知道原因。  
随着时间的慢慢，森林重新呼吸 -- 藤蔓缠绕着一切痕迹，野花从石头的裂缝中绽放。一切人类文明都渐渐被苔藓覆盖，自然又重新占领了世界。但人类留下的东西  -- 被动物们偷偷利用了起来，家具、甚至是那些建筑。  
你是一只瓢虫，一只浑身疲惫。艰难前行的瓢虫，为了寻找一点能果腹的浆果，只能勉强撑起身体踏入深处，却不慎闯入了变异植物的领地，虚弱让你无力去挣脱。  
就在这时，一道棕褐色的身影猛地撞开藤蔓，是一只水獭，他叼着你飞快逃离了这片危险地带。

水獭将你带回了他的家，又递来几颗甜嫩的野果。你缓过劲后才发现 -- 这根本不能算是家 -- 一个破败，满是灰尘的屋子，只能勉强有个休憩的角落

为了报答水獭的救命之恩，也想让他有个安稳的居所，你开始用小小的足尖拨开落叶，在遗迹的角落收集被遗忘的“珍宝”：各种各样被遗弃在丛林里的家具。每一次探索都有惊喜，你和水獭的关系渐渐靠近，水獭不仅接受了你成为他的家人，还把他真正的家人带来 -- 他终于把这块居所当做了自己的家

当温馨的家园取代了过去的废墟。你忽然懂得，这片被人类“放弃”的土地，从不需要谁来定义或守护。风依旧吹过树梢，植物依旧蓬勃生长，而你们，正用彼此的陪伴，在寂静的遗迹里，重新织就最温暖的生活。

# 人物设定

- 水獭哥哥：排行第二，外向话多，典型的行动派，性格极度乐观，有很明显的收集癖，喜欢捡一切亮晶晶、造型奇特的人类遗留小物件，是家里的“气氛担当”与“探索先锋”。
- 水獭妹妹：排行老大，自带工匠天赋。外表强壮可靠，爪子灵活擅长打磨、搭建；内在却格外喜欢可爱的东西，会把收集的柔软材料做成小摆件，还有点胆小，尤其害怕黑暗，天黑后几乎不敢独自外出。
- 水獭姐姐（糯糯）：外表小巧可爱，看上去最柔弱，实则内心强大，是家里真正的靠山。擅长观察环境、规划安排，能在危机中保持冷静，会用温柔的方式安抚家人情绪，也能在关键时刻做出决断。

# 详细剧情：

#### 一、背景

在很久以前，河流还沿着人类修筑的石岸流淌。水獭一家就住在那条河边。不是很大的家，但足够安全——河水清澈，鱼群稳定，岸边的木桥能遮风挡雨。他们知道人类的存在，却从未真正理解那些高大的生物，只知道河水会被清理，危险的地方会被围起，但也有人会来把他们的邻居带走......

人类离开的那一天，安静得就像一片落叶飘入河中。清晨的河岸上再也没有脚步声，世界仿佛屏住了呼吸。

起初，生活似乎没有什么不同。水獭们依然每天在河中嬉戏。但渐渐地，桥梁开始发出吱呀声，藤蔓悄悄爬满了河道。鱼群游向别处，河水越来越浅。

“我们会找到新的家园。”一个清晨，水獭爸爸和妈妈这样说

水獭哥哥、妹妹和姐姐在岸边等啊等，等到植物覆盖住了一切。

 

#### 二、三只水獭的故事

三只小水獭选择了不同的方式继续生活。

水獭哥哥是最先接受现实的。他开始频繁外出，记下每一条还能通行的路线，把一切“可能有用”的东西拖回临时的栖身之所。破碎的家具、掉落的木板、生锈的金属、脆弱的纸箱......

他什么都不舍得丢。

他总是说话很多，把危险描述得很轻，像在开玩笑玩笑。

对他来说，向前走是唯一的办法。

 

水獭妹妹没有走得那么远。她留在临时居所附近，开始拆解、修补人类留下的东西 -- 为周围的邻居修补它们的家，她不喜欢黑暗，不喜欢孤单的感觉

 

水獭姐姐离开得最晚。她一直在等——等父母回来，等河水恢复，等这个世界重新变得有秩序。

 

#### 四、瓢虫的加入

直到一个雨天，一切都开始改变。

哥哥在探险时救下了一只受伤的瓢虫 -- 他似乎有些自来熟？

“你的收集品都很棒，”瓢虫看着哥哥落脚的地方说到，“但如果再多一些家具，把它们整理一下会更好

寻哥哥第一次停下了脚步，认真地看着自己杂乱无章的收藏。

在瓢虫的帮助下，他们一起把收集到的旧家具拼成温暖的家

“我们需要一个帮手！”哥哥说到“要是我姐姐在就好了，她什么都会修。”

 

瓢虫在竟然真的路上碰到了刚刚修补完邻居家的姐姐

 

姐姐第一次走进哥哥的屋子时，惊讶地睁大了眼睛。

“这些……都是你找到的？”她抚摸着光滑的木板，看着逐渐成型的家。

“是的，但是你知道的，我手艺根本没有你的好”哥哥说

 

随着屋子一天天变得温馨，一个念头在两只水獭心中萌芽：还缺一个人。

妹妹被邀请踏进这个房子时屋子时，她愣住了。

这不是她记忆中那个冰冷、破败的地方 --完全变了个样

 

“这里……”妹妹轻声说，“这里好像我们之前的家。”

 

#### 五、最后的最后

那天晚上，三只水獭和一只瓢虫围坐在新做的桌子旁。桌上摆着甜美的浆果，窗外的月光温柔地照进来。

“我明天要去探索东边的那片蒲公英田，”哥哥说，“听说那里有一种会发光的石头。”

“我可以做几个小篮子装石头，”姐姐已经开始计划，“用柔韧的柳条编。”

“我想在屋后种一片浆果丛，”妹妹轻声说，这是她第一次说起未来的计划，而不是过去的回忆，“这样每个季节都有果实，想怎么吃都可以。”
