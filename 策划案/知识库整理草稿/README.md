## 当前版本口径

- 项目核心不再按“纯装修”理解，而是“野外探索 × 家园装修”的双循环休闲冒险。
- 家园是贴纸生产、情感反馈和长期承载，野外是材料、家具、蓝图、节奏反差和轻度压力来源。
- 舒适度系统已删除；当前以“贴纸金钱系统 + 蓝图 + 家园扩建 + 能力投资”承载成长。
- 小动物不是第三个并列玩法板块，而是家园装修的情感反馈、贴纸反馈和叙事驱动力。
- 最新可信源优先级：9.15相关《循环》《循环详细策划案》《驱动力》、2026-07 的《野外》、2026-06 的《工具台系统策划案》《家园UI修改》。1-3月文档主要作为细节来源或历史参考。
