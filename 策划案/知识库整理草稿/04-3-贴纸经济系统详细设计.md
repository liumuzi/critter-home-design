# 贴纸经济系统详细设计

## 系统定位

贴纸是当前版本的唯一核心硬通货，用来替代旧舒适度系统承担成长推进。贴纸把家园和野外绑定：玩家通过照顾小动物和布置家园获得贴纸，再用贴纸投资野外能力和家园扩建。

## 经济闭环

```text
野外获得材料 / 家具 / 蓝图
  -> 回家制作与摆放家具
  -> 小动物根据家具状态产生贴纸
  -> 玩家领取贴纸
  -> 投资能力或家园扩建
  -> 野外效率提升 / 家园空间扩大
  -> 新材料、新蓝图、新需求出现
```

## 贴纸产出

### 产出主体

贴纸由小动物产生，不由野外直接掉落。家园是主要收入来源。

### 触发条件

V1建议先采用确定触发，降低测试复杂度：

| 触发 | 说明 |
|-|-|
| 首次摆放家具 | 该家具对应小动物进入可反馈状态 |
| 放置成套家具 | 产生较多贴纸反馈 |
| 小动物新需求完成 | 产生一次性贴纸奖励 |
| 家园扩建完成 | 新需求或新小动物带来后续贴纸产出 |

暂不建议V1做复杂离线收益。源文档提到“现实时间绑定”但仍待定；如果要做时间收益，应限制领取频率和上限，避免变成挂机经济。

## 领取流程

1. 家具或需求满足后，小动物进入“可给贴纸”状态。
2. 小动物头上出现贴纸气泡。
3. 玩家靠近并点击气泡。
4. 触发一句短对话或感谢反馈。
5. 气泡消失，贴纸飞入货币栏。
6. 若贴纸达到某投资条件，显示可升级/可扩建提示。

## 贴纸数值原则

- 新摆放家具给少量贴纸。
- 成套家具或关键需求给较多贴纸。
- 高级家具不应无限碾压普通家具，避免只追高稀有度。
- 小动物喜好与贴纸数量是否绑定待定；V1可先不绑定，避免复杂度过高。

## 消费端总览

贴纸有两条去向：弱路径“售卖变现”，强路径“投资”。

| 路径 | 定位 | 是否主循环 |
|-|-|-|
| 售卖变现 | 救急、加速、短期补缺 | 否 |
| 投资能力 | 强化野外探索效率 | 是 |
| 投资家园扩建 | 扩大空间、解锁蓝图、新动物和新需求 | 是 |

## 售卖变现

售卖必须存在但不能舒服。它参考《潜水员戴夫》仓库/商城界面，由玩家主动打开兑换界面，决定卖多少贴纸、换什么资源。

### 约束

- 不做自动售卖。
- 不做一键清空。
- 汇率不应高到让玩家优先卖光贴纸。
- 可考虑每日售卖次数或数量限制，待定。

## 投资能力

能力投资是强路径之一。它通过三个固定栏位升级，不做随机词条。详细规则见 [主角能力升级详细设计](06-1-主角能力升级详细设计.md)。

### 升级方向

| 方向 | 野外影响 |
|-|-|
| 手电/光源 | 提升视野、续航、资源/宝箱信号辨识和撤离容错 |
| 背包/负重 | 能带更多物品，降低超重惩罚，改变撤离压力 |
| 机动/隐匿 | 提高探索效率、脱险能力或降低被发现压力 |

### 升级流程

1. 玩家打开能力投资界面。
2. 选择固定栏位。
3. 查看当前等级、下一级效果、贴纸消耗。
4. 若贴纸足够，点击升级。
5. 扣除贴纸，播放升级反馈。
6. 新效果生效。生效时机待定：V1建议下次进入野外生效，便于测试和避免中途状态刷新问题。

## 投资家园扩建

家园扩建是另一条强路径，也是驱动下一轮野外探索的核心引擎。

### 扩建结果

- 打开第二个房间、第三个房间或新屋。
- 物理空间扩大，可摆更多家具。
- 解锁新家具蓝图。
- 新小动物入住。
- 已入住小动物提出新需求。
- 外围装饰或氛围产生小变化。

### 扩建流程

1. 玩家打开扩建界面或靠近扩建点。
2. UI显示扩建名称、预览、消耗贴纸、附加条件。
3. 玩家确认扩建。
4. 扣除贴纸。
5. 播放扩建反馈。
6. 解锁空间和蓝图。
7. 触发新小动物或新需求。
8. 新需求转化为野外目标。

## 特殊家具 Buff

特殊家具提供轻微被动Buff，主要作用于野外，但不是主要能力来源。

### 规则

- 只在家具处于 placed 状态时生效。
- 同类Buff有上限。
- Buff数值小于能力投资同方向升级。
- 若家具被收回仓库，Buff失效。

## UI入口

| UI | 作用 |
|-|-|
| 货币栏 | 显示当前贴纸数量 |
| 小动物气泡 | 领取贴纸入口 |
| 售卖界面 | 贴纸变现弱路径 |
| 能力投资界面 | 固定装备栏位升级 |
| 家园扩建界面 | 房间/新屋/蓝图/小动物解锁 |

## 实现验收

- 贴纸不进入背包，进入货币栏。
- 小动物可生成贴纸气泡，点击后领取贴纸。
- 贴纸可被能力升级消耗。
- 贴纸可被家园扩建消耗。
- 售卖入口存在但无自动清空。
- 扩建能触发蓝图、新需求或新小动物中至少一种后续内容。
