# 主角能力设计文档

## 第 1 页

主⻆能⼒设计⽂档
主⻆本体设定：
主⻆物种：瓢⾍
核⼼玩法：类超⾃然追逃玩法
基于这种玩法设计，主⻆的能⼒主要是躲避，不具备攻击能⼒。所以设计上，主动技能应
以⽣存、躲避为主要⽬标。
在主⻆能⼒维度上，基于搜索、逃脱、收纳进⾏数值维度设计与成⻓。数值成⻓主要体现
在图腾和装备上。
主⻆三维：
⾎量：1点（后期可以考虑升级成2点）
移速：3m /s（需⽀持配置，后续⼤概率要调整，并⽀持其他参数介⼊，更改这项数值）
起停步加速度：20m /s²（需⽀持配置）
转向加速度：40m /s²
负重：50kg（需⽀持配置，以及其他参数介⼊更改数值）
空⼿背包格⼦数：8个（需⽀持配置，以及其他参数介⼊更改数值）
安全箱格⼦数：1个（需⽀持配置，以及其他参数介⼊更改数值）
可装备栏位：
鞋⼦1个、护甲1个、主动技能槽1个、图腾栏位2-3个、背包栏位1个
鞋⼦：提供移动速度和被动⽣效的技能
鞋⼦设计：
⚪ 隐⾝鞋：移动速度+1m /s，被动效果：每20秒，隐⾝3秒
⚪ 负重鞋：移动速度+0.6m /s，被动效果：主⻆负重能⼒+10kg
⚪ 急速鞋：移动速度+1.5m /s
护甲：抵挡⼀次致命伤
在有护甲的状态下，当主⻆受到致命伤时，进⼊虚⽆状态3秒。
虚⽆状态：主⻆对怪物的碰撞消失，主⻆可以穿过怪物，怪物失去主⻆视野，停⽌追击
护甲未来的成⻓可以做成多⼏条命这样，颗粒度稍微粗⼀点，作为主要追求
护甲剩余⼏格防御需要⽤⾖或条的形式，展⽰在主⻆头顶/脚底/⻚⾯⼀⻆，使玩家能清晰
地看⻅当前剩余⾎量。

⚪ 隐⾝：主⻆进⼊隐⾝状态5秒，怪物⽴刻清空对主⻆的仇恨停⽌追击，隐⾝期间怪物失
去主⻆视野。但这种状态下如果主⻆撞到敌⼈或远程攻击还是会掉⾎。cd40s。
⚪ 起⻜：瓢⾍振翅，向某⼀⽅向沿直线⻜⾏，速度15m /s，持续1秒。⻜⾏设定上是在空
中进⾏的，所以⻜⾏过程中不会撞到怪物或远程攻击的⼦弹。⻜⾏不能越过地形，遇到地
形会停下，但在1秒钟的持续时间结束后才落地。cd25s。
⚪ 甲壳：主⻆硬化⾃⼰的甲壳，持续3s，期间怪物与主⻆发⽣碰撞则会以20m /s的速度
被弹开6m 。技能持续期间免疫怪物碰撞和远程攻击。cd30s。
⚪ 翻越：主⻆朝墙体⽅向释放技能，技能有⼀定的判定范围（2m 内）。如果判定范围与
墙体/障碍物重合，则主⻆触发翻越判定，翻过本来不可以通过的墙体。如果判定检测失
败，则技能释放不成功，不消耗任何资源，技能也不会进⼊CD。CD25s。
⚪ 奔跑：主⻆进⼊疾跑状态，在3秒内移速线性增加⾄130%，到达满速后，持续5秒。
CD40s。
图腾：提供被动的数值加成，或某项特殊功能
图腾栏位前期可以只开放⼀个，中后期增加图腾栏位。
每种图腾应分为三档，三档有数值强度差距。
此处仅举例说明，不代表全部设计
⚪ 搬运图腾：主⻆可容纳的物品格⼦+30%，负重能⼒提升20%（注：最好⽤百分⽐数
值，三档有不同的百分⽐配置）
⚪ 毒抗图腾：延⻓能够抵挡毒⽓侵蚀的时间。
毒：地图区域特性，部分地区充满毒⽓，玩家在毒⽓中待满10秒则会死亡，⽆视护
甲。
1级毒抗：在毒⽓中可存活的时间提升⾄1分钟
2级毒抗：2分钟
3级毒抗：免疫毒⽓效果
⚪ 窃贼图腾：加快主⻆搜索物资速度。20%、40%、70%
为体现搜打撤的紧张与压迫感，主⻆开箱时，根据物品的贵重程度需要转菊花。不同
等级的物品推荐转菊花时间从0.5s-2s排列，且最好不是等差数列，⽽是等级越⾼增加更
多时间。
⚪ 轻巧图腾：降低减速区域的减速效果。
部分怪物/地区可以在地图上释放/存在减速区域，可以包装为泥沼等。区域可以设定
⼀个默认的减速值百分⽐，⽽拥有这个图腾则可以降低减速的百分⽐。减速效果减弱
30%、60%、100%。
⚪ ⼤师图腾：主动技能效果持续时间增加。即隐⾝、奔跑的持续时间增加。10%、
20%、40%。
⚪ 感知图腾：视野范围增加、听⼒范围增加。20%、30%、50%。装备此类图腾时，解
锁可视化听⼒效果。
⚪ 急速图腾：主⻆移动速度提升。10%、12%、15%
