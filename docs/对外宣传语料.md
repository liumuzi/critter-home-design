# 《虫虫装修》对外宣传语料

本文档统一收录《虫虫装修》已经定稿、可直接对外使用的中文宣传文案。文案应面向普通玩家，优先传达玩家能做什么、能感受到什么，以及最终为何值得坚持。

## 游戏介绍

### 主宣传语

把破木屋，装成末世最幸福的家！

### 传播钩子

**末世捡垃圾，回家爆改避难所——怎么越捡越上头？**

> 适用于短视频标题、社交媒体帖子等强调第一眼吸引力的传播场景，不作为正式商店页的主宣传语。

### 标准版

人类已经消失——

森林吞没了昔日的城市，黑暗中潜伏着危险。或许一切美好都终将消逝……

可即使这样，你也想要和小伙伴们幸福快乐地生活在一起。

所以，开动脑筋，出发吧！潜入废墟，翻找材料和珍稀家具，装点伙伴们的房间。

只是千万当心：灯光之外，变异植物正悄悄逼近……完了，被发现了——快带上宝贝逃回家！

还好小伙伴在家等你：“辛苦啦，休息休息，喝口热茶吧。”

扩建房屋，结识朋友，学习本领，重新出发！

“难道，这就是失落已久的宜家沙发？我做梦都想要这个！”

就这样，破旧的小木屋渐渐变成明亮、宽敞的大房子，避难所成了热闹的家。

末世还在继续，你们的幸福也是。

### 缩减版

人类已经消失——森林吞没城市，黑暗中潜伏着危险。

可即使如此，你也想和小伙伴们在这末世快乐生活。

所以，开动脑筋，出发吧！潜入废墟，寻找珍稀家具……完了，被发现了——快逃回家！

还好小伙伴在家等你：“辛苦啦，休息休息，喝口热茶吧。”

扩建房屋，结识朋友，学习本领，重新出发！

“难道，这就是失落已久的宜家沙发？我做梦都想要这个！”

世界依然危险，但你已经有了明亮、热闹的家。
