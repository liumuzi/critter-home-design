# 《虫虫装修》项目概览 One-Page

> **面向对象**：团队内部开发人员（美术、音乐及新加入成员）
> **文档目的**：明确项目方向、核心玩法及游戏架构，帮助团队快速理解游戏整体概况

---

## 一、我们的初心：为什么要做这款游戏?

### 核心体验：持续的心流

**一张一弛、一松一紧的双循环体验**——野外探索带来紧张刺激，家园装修带来放松治愈。两个板块互为补充，营造持续的心流状态，让玩家"停不下来"。

我们想要传递的体验：

- 🎯 **上头的节奏**：野外与家园的反差形成强烈吸引力，紧张与放松的切换让人欲罢不能
- 🏠 **装修的满足**：收集资源、制作家具、布置家园，看到自己的成果被使用
- 💝 **情感的驱动**：小动物提供情感价值和动力，让装修更有意义

### 核心玩法定位

**野外做“休闲化搜打撤”，家园做“装修 + 模拟经营”。** 两端共同服务于“守护与陪伴”：因为野外危险，家园才显得温暖；因为小动物会在家里生活并回应玩家，搜集与装修才有情感意义。

整体采用类似于**《潜水员戴夫》**的双循环模式：

- **捕鱼 ↔ 卖寿司** ≈ **野外探索 ↔ 家园装修**
- 野外获得资源 → 家园装修升级 → 解锁新能力 → 探索更深区域 → 循环往复
- 搜打撤的核心体验保留为：搜索高价值物资、在风险中取舍、成功撤离并把收获带回家；通过非硬核战斗、短局追逃和较低操作门槛实现休闲化
- 模拟经营的核心体验落实为：制造与摆放家具、满足住户需求、获得虫币/贴纸反馈，再投资能力、扩建与新内容

## 二、游戏是什么？一句话说明

**一款融合“休闲化搜打撤 × 装修模拟经营”双循环玩法的休闲冒险游戏**

玩家扮演一只小小的瓢虫，在人类消失后的末世森林中拾荒，躲避被寄生植物侵袭的危险，把废墟中的材料变成家具，为小动物们装修温暖的家园。

---

## 三、核心玩法循环

![核心游戏循环](./Art/diagrams/core-gameplay-loop.svg)

### 循环说明

核心循环发生在**野外探索**和**家园装修**两个板块之间：

1. **搜（搜索）**：进入迷雾笼罩的野外，寻找材料、家具、蓝图、饰品与高价值宝箱
2. **取舍与撤离**：负重会拖慢移动，光源与冲刺资源有限，玩家必须判断继续深入还是带着收获撤离；越贪越危险，带走才算赢
3. **装修与经营**：回家后在工作台制造家具、调整布局、满足小动物需求，获得虫币/贴纸与情感回应
4. **投资与扩建**：把经营收益投入野外能力、房屋扩建和新地图，形成下一轮搜集目标

**小动物的作用**：作为情感驱动力和家园住户，通过使用家具、反馈装修、提出心愿和记录共同生活，让经营不只是数值循环。它们不与野外、家园并列为第三板块，但会直接推动家园目标与下一轮探索。

---

## 四、游戏节奏：一张一弛

![游戏情绪节奏曲线](./Art/diagrams/emotion-curve.svg)

### 节奏特点

- **野外（张）**：微恐氛围下的轻量搜打撤；在有限视野中搜索、管理负重和体力、躲避与周旋、择机撤离
- **家园（弛）**：装修 + 模拟经营；制造、摆放、出售或投入家具，欣赏成果，与小动物共同生活
- **反差互补**：两个板块形成强烈对比，互为补充，营造"停不下来"的体验

**整体节奏**：10分钟Demo中，家园操作占比≥45%

## 六、各系统简述

### 6.1 野外探索系统

**定位**：提供休闲化“搜打撤”体验，是资源的主要来源

| 子系统             | 作用                                           |
| ------------------ | ---------------------------------------------- |
| **采集系统** | 玩家在森林中开启宝箱，收集家具、材料和饰品     |
| **追逐躲避** | 需要躲避危险，通过隐身、负重管理等方式生存     |
| **背包管理** | 负重影响移动速度和被发现概率，需权衡收益与风险 |
| **主角能力** | 瓢虫可装备饰品、使用技能，通过成长提升生存能力 |

**关键博弈**：

- 迷雾与有限光照制造对未知的微恐，而不是靠复杂操作施压
- 负重越高移动越慢；面对威胁以绕行、隐蔽和逃脱为主，不能常规硬刚
- 冲刺体力既能保障逃命，也可被玩家主动用于追逐高价值目标
- “会跑的宝箱”等事件迫使玩家瞬间判断：继续追逐，还是保住现有收获撤离

### 6.2 家园装修系统

**定位**：以“装修 + 模拟经营”构成放松治愈的核心体验，玩家投入时间占比≥45%

| 子系统               | 作用                                                     |
| -------------------- | -------------------------------------------------------- |
| **装修系统**   | 自由摆放家具，通过风格搭配和空间布置实现个性化表达       |
| **工作台**     | 使用材料合成中高级家具，通过蓝图与进度条件解锁新内容     |
| **小动物互动** | AI小动物作为情感驱动力，提供装修反馈和动力，增强情感连接 |

经营不是独立于装修的菜单玩法，而是从装修行为自然产生：摆放新家具、调整布局、满足住户需求和迎接新伙伴会带来虫币/贴纸；收益再用于野外能力、房屋扩建、新地图和新内容。行走/沉浸模式允许玩家进入自己创造的空间，靠近小动物并触发互动，强调共同生活与过程乐趣，而不是只追求数值最优。

**小动物定位**：属于家园装修板块下的重要子系统，提供情感价值，但不是与野外、家园同级的独立板块

### 6.3 核心共享系统

| 系统               | 作用                                           |
| ------------------ | ---------------------------------------------- |
| **任务系统** | 主线推进游戏进度，支线丰富内容                 |
| **物品系统** | 统一管理家具、饰品、材料                       |
| **成长系统** | 通过装备升级、能力解锁、新区域开放实现长线成长 |
| **怪物AI**   | 提供探索张力和挑战                             |

## 七、设计原则与理念

### 核心原则

1. **节奏优先**：野外与家园的反差营造"一张一弛"的持续心流
2. **循环紧密**：双循环互相驱动，形成"停不下来"的上头体验
3. **情感增益**：小动物提供情感价值，让装修更有意义
4. **温和挑战**：紧张但不折磨，有风险但可控制

### 与《潜水员戴夫》的相似之处

| 《潜水员戴夫》     | 《虫虫装修》     |
| ------------------ | ---------------- |
| 白天捕鱼（紧张）   | 野外探索（紧张） |
| 晚上卖寿司（放松） | 家园装修（放松） |
| 升级装备           | 解锁能力         |
| 探索更深海域       | 探索新区域       |
| 经营餐厅           | 装修家园         |

### 灵感来源与差异化

团队最初因共同喜爱《潜水员戴夫》的一张一弛双循环而形成方向，又从搜打撤产品的基地建设中看到进一步扩展的空间：如果把基地建设深化为真正的装修与模拟经营，野外风险、回家兑现和长期建设会互相增强。《虫虫装修》的差异化不是简单复刻某一款参考游戏，而是在已被验证的“冒险 + 经营”结构中，进一步占据“休闲化搜打撤 + 装修”的组合位置，并用AI小动物补上个性化陪伴。

## 八、世界观（简化版）

**设定**：人类已经消失，玩家是一只生活在末世森林中的小小瓢虫。野外废墟受到寄生植物侵袭，玩家从危险区域拾荒，将人类留下的材料转化为小动物的新家。

**环境**：森林被迷雾笼罩，有限视角和光照让探索带有微恐感；废墟中有资源、宝藏和会移动的高价值目标，也有需要绕行、隐蔽和逃脱的危险。

**目标**：通过探索收集资源，为小动物们打造舒适的家，让玩家感到自己在危险世界中守护它们。核心情绪不是征服，而是**守护与陪伴**。

---

## 九、技术特色：AI驱动的情感体验

### AI系统的作用

小动物通过AI技术实现：

- 记住玩家带回了什么、怎样布置房间、是否平安回家等共同经历
- 根据装修风格给出真实反应
- 在不同心情下展现不同性格
- 主动表达需求和情感
- 把关键共同经历写入小动物日记，并随关系加深解锁其个人故事和心愿

**定位**：不是泛聊功能，而是把玩家行为转化为“它记得我”的定制化陪伴，增强沉浸感、分享欲和对家园建设的情感驱动力。

---

## 十、目标玩家与体验目标

### 目标玩家

核心目标是 **18-25 岁、偏好二次元审美与休闲治愈体验的年轻女性玩家**，尤其是喜欢《星露谷物语》《潜水员戴夫》式“探索 + 模拟经营”组合、觉得纯经营偏平淡又不想承受硬核搜打撤门槛的人群。独特画风、题材和玩法反差同时承担吸引泛用户尝鲜的作用。

### 期望体验

- 🎯 **停不下来**：野外与家园的反差形成强烈吸引力，一张一弛让人上头
- 🎨 **装修的成就**：自由布置，看到成果被使用，获得满足感
- ⚡ **探索的刺激**：适度紧张的野外冒险，逃脱后的成就感
- 💗 **情感的温暖**：小动物提供情感价值，让装修更有意义

## 十一、内容结构与长线扩展

- **长期主线**：按章节推进世界与完整循环，在野外救助/结识新动物，回家建设并获得角色反馈，再开启下一阶段目标
- **中期支线**：围绕每只小动物的个人故事、关系与专属家具展开
- **短期心愿**：持续提供收集、制造、装修和探索目标，并消耗多余材料与家具
- **模块化更新**：新地图、新角色入住、新家具/家具主题与季节活动都回到同一双循环，不破坏已有系统
- **社区传播**：装修作品和AI小动物的个性化共同回忆具有天然分享性，可围绕晒家、故事与活动形成温馨活跃的玩家社区

## 结语

这是一款以**休闲化搜打撤 + 装修模拟经营**让玩家体验**守护与陪伴**的游戏。

野外的紧张与家园的放松形成反差，两个板块互为补充。
小动物提供情感驱动，让装修更有意义。
我们追求的是让玩家"停不下来"的上头体验。

**一张一弛，持续心流——这就是我们的核心。**
