## 二、项目概要

《虫虫家装》是一款融合"搜打撤 × 家园装修"双循环玩法的休闲冒险游戏，是目前市场上**唯一**将这两个高增长赛道深度融合的产品。

**核心体验**：玩家扮演一只瓢虫，在人类消失后的末日森林中探索废墟、搜刮资源、躲避变异植物的追逐——紧张刺激的"搜打撤"冒险；回家后，用收集到的家具和材料为小动物们布置温暖的家——放松治愈的"装修"时光。一松一紧、一张一弛，形成类似《潜水员戴夫》"白天潜水捕鱼→晚上经营寿司店"的上瘾节奏。

**差异化定位**：搜打撤品类全球火热（《逃离塔科夫》峰值在线20万、《逃离鸭科夫》500万+套），装修品类长线稳定（《房产达人》300万+套、《我的休闲时光》国服流水7000万），但**两者的交集目前是蓝海**。我们将硬核搜打撤轻量化为休闲玩家可接受的轻度冒险，以装修为情感锚点、以冒险为资源引擎，兼顾两类用户的需求。

**AI技术深度整合**：小动物NPC由大语言模型驱动，可根据玩家行为、关系阶段和历史记忆生成个性化情感反馈——不是预设台词，而是"它记得你做过什么"。AI不是附加功能，而是让装修行为被角色真正"看见并回应"的核心机制。

**早期试玩信号**：累计19份结构化问卷中，100%表示期待后续内容，95%想继续装修，家园与野外整体体验正向率分别为95%和89%，84%对按同类价格或更高意愿购买持开放态度。这组小样本只能说明产品方向值得继续验证，不能代表整体市场结论。

**团队优势**：7人团队横跨游戏策划、美术设计、AI工程、程序开发。技术负责人毕业于香港中文大学计算机科学专业，拥有米哈游4年中台算法经验；主策划曾在北京搜狐实习，现就职于一线出海游戏公司。团队具备美术、策划、程序的完整能力闭环，并已获得2026光子游戏大赛概念赛道银奖。

**荣誉**：2026光子游戏大赛概念赛道 **银奖**。

## 三、市场分析

### 目标市场

全球游戏市场2025年收入达 **$2016亿**（Newzoo），Steam平台2026年上半年收入 **$111亿**，同比增长14.5%。本项目锚定Steam平台（PC端首发），后续可拓展至移动端和主机平台。

### 核心用户画像

| 维度       | 特征                                                   |
| ---------- | ------------------------------------------------------ |
| 年龄       | 18-30岁为主（19份早期样本中74%为18-25岁）              |
| 性别       | 女性占比高（19份早期样本中68%为女性），兼顾男性玩家    |
| 游戏偏好   | 喜欢装修/收集/模拟经营类游戏，同时对轻度冒险持开放态度 |
| 消费特征   | 19份早期样本中84%对按同类价格或更高意愿购买持开放态度  |
| 对标用户群 | 《星露谷物语》《潜水员戴夫》《动物森友会》的玩家群体   |

### 两个赛道的市场规模验证

**搜打撤赛道**：Krafton公开表示"搜打撤是下一个大品类"。《逃离塔科夫》峰值20万在线、《逃离鸭科夫》500万+套、《Arc Raiders》400万+套——品类正处于高速增长期，大厂密集布局（Krafton、Bungie、Embark、腾讯）。

**装修赛道**：《房产达人》300万+套、《Unpacking》100万+套，品类用户付费意愿稳定、长线运营能力强。国内《我的休闲时光》以个位数研发团队实现7000万流水、运营3年仍在增长，证明小体量装修产品也能实现可观商业回报。

### 市场空白与机会窗口

两个赛道目前完全独立运行，但交叉验证数据表明市场存在巨大需求：

- 《星露谷物语》（5000万套）证明：喜欢种田/社交的休闲玩家愿意接受洞穴战斗。
- 《潜水员戴夫》（500万+套）证明：冒险+经营的"松紧交替"节奏让人上瘾。
- **我们填补的是"搜打撤 × 装修"的交叉空白**——这是两个已验证赛道之间的蓝海。

### 增长空间

当前只承诺完成Steam PC首发及首发后的必要维护。DLC、主机或移动端均属于条件性上行选项，只有在本体销量、留存、玩家反馈和团队现金流达到预设门槛后才立项，不纳入本轮融资必须交付范围。

## 四、竞争分析

### 是否有主要竞争对手

**否** —— 在"搜打撤 × 装修"双赛道融合领域，目前市场**无直接竞品**。

原因分析：

1. **搜打撤品类头部产品均为硬核向**（《逃离塔科夫》《Hunt: Showdown》《Arc Raiders》），目标用户是硬核战术射击玩家，与休闲装修用户几乎不重叠。
2. **装修品类头部产品均为纯装修/模拟经营**（《房产达人》《Unpacking》《我的休闲时光》），不包含冒险战斗元素。
3. **双循环品类（探索+经营）已验证但方向不同**：《潜水员戴夫》是潜水捕鱼+寿司经营、《Moonlighter》是地牢战斗+商店经营——均未切入"装修/家居布置"赛道。

### 相邻赛道竞争格局

| 竞争对手                            | 品类            |        是否上市        | 市场表现                   | 与本项目关系                       |
| ----------------------------------- | --------------- | :---------------------: | -------------------------- | ---------------------------------- |
| Battlestate Games（《逃离塔科夫》） | 搜打撤          |           否           | 峰值在线20万，买断$45-$250 | 品类定义者，但硬核向，目标用户不同 |
| Frozen District（《房产达人》）     | 纯装修          |           否           | 300万+套销量               | 装修品类标杆，但无冒险元素         |
| MINTROCKET（《潜水员戴夫》）        | 双循环          | 母公司Nexon（东京上市） | 500万+套                   | 节奏模型最接近，但玩法组合不同     |
| 《我的休闲时光》                    | 纯装修+模拟经营 |           否           | 国服流水7000万，运营3年+   | 验证装修付费潜力，但无冒险元素     |

### 竞争优势

**1. 赛道独占性（核心壁垒）**

我们是目前市场上**唯一**将"搜打撤"与"装修"深度融合的产品。两个赛道各自已有百亿级市场验证，但交叉地带完全空白。这既是先发优势，也是品类定义者的机会——参照《逃离塔科夫》定义搜打撤品类、《房产达人》定义纯装修品类的路径，我们有机会定义"冒险装修"这一新子品类。

**2. 双循环节奏的成瘾性已验证**

《潜水员戴夫》（500万+套）和《Moonlighter》（100万+套）充分证明"紧张探索+放松经营"的双循环节奏具有极强的用户粘性。我们在同样的节奏框架下，替换了更具差异化、更贴合女性/休闲用户偏好的"装修"玩法，降低了用户获取门槛。

**3. 试玩反馈提供早期方向信号**

累计19份结构化问卷中，家园与野外整体体验正向率分别为95%和89%，100%玩家期待后续内容，95%想继续装修，84%对按同类价格或更高意愿购买持开放态度。由于样本量小、试玩时间短，这些结果仅作为“核心循环值得继续打磨”的方向性早期信号；下一阶段将结合更大样本试玩、Steam愿望单和Demo行为数据继续验证。

**4. AI构建情感护城河**

小动物NPC由LLM驱动，记住玩家行为并生成个性化反馈——这不是"更好看的装修游戏"，而是"小动物真的会因为你的装修而感动"。情感体验难以被竞品简单复制，构成长期竞争壁垒。

**5. 团队效率与执行力**

7人团队在有限时间内完成从概念到可玩Demo的全流程交付，并获得2026光子游戏大赛概念赛道银奖。精干团队意味着更低的运营成本、更快的迭代速度、更统一的创作方向。

## 五、产品与商业模式

### 收入模式：Steam买断制

**1. 首发买断（基础收入）**

Steam平台首发，计划标价参考同类独立游戏的$15-$25区间，财务模型按折扣、区域价格和退款后的人民币80元平均成交额测算。19份早期问卷中，84%玩家对按同类价格或更高意愿购买持开放态度，但问卷没有验证具体价格点，因此最终定价仍需结合愿望单、Demo转化、发行建议和区域价格测试确定。

**2. 首发后扩展内容（条件性选项）**

首发后先完成稳定性维护并复盘本体销量、退款率、好评率、留存与现金流。只有数据达到立项目标后，团队才评估付费DLC、新平台或新增语言；目前不预设固定赛季数量、DLC定价或外观内购收入，也不将这些项目计入基准财务预测。

### 盈利预期

对标产品：《Moonlighter》（Digital Sun，~8人初创期）累计100万+套，$19.99定价，有发行商加持。我们把首发12个月15万套作为待验证的基准经营目标。**注：2027年Q4首发，故日历2027年仅含约2.5个月销售窗口；核心财务判断统一采用“首发12个月”，不额外承诺更远期销量。**

| 情景    | 首发12个月销量 | 回收300万元新增现金需求后的结余 | 触发条件                    |
| ------- | :------------: | :--------------: | --------------------------- |
| 🟢 乐观 |     30万套     |     ¥1,270万     | 接近优秀相邻产品量级，Demo与自然传播充分兑现 |
| 🟡 基准 |     15万套     |     ¥510万     | 正常Steam独立游戏发行节奏   |
| 🔴 保守 |     5万套     |     -¥20万     | 接近静态盈亏平衡点，需控制上线后投入 |

> **突破性上行不进入主财务承诺**：若产品成为装修品类代表作，长期销量上行空间可参考《Unpacking》约66.3万套的第三方估算快照；该数字与本项目的首发12个月口径并不相同，因此不列为普通“乐观预测”。

> **统一口径**：按每套平均含税成交额80元、Steam平台费30%测算，并把本轮300万元完成首发新增现金需求作为需要整体收回的投资基础。基准情景下，15万套对应1,200万元消费者支付总额、840万元平台费后收入；再扣除300万元投资基础及30万元税费预留，结余约510万元。该数字是项目投资回收口径，不等同于经审计会计净利润。

## 六、发行与市场进入策略

### 首发市场与发行原则

项目计划以 **Steam PC端全球首发** 作为第一阶段市场入口，首发语言暂按简体中文、英文和日文规划。现阶段的核心任务不是同时铺开主机、移动端和多地区发行，而是先通过Steam商店页、公开Demo和平台活动验证产品定位、用户兴趣与购买意愿，再决定是否扩大平台和语言范围。

发行策略采用“**自发行能力先行、发行合作保留选择权**”的原则。团队自行掌握商店页、社区、数据归因和基础内容营销能力；同时接触具备独立游戏、海外市场或主机移植经验的发行伙伴。是否签约不以“获得曝光”作为唯一标准，而以其能否提供团队短期内难以自建的能力为判断依据，包括平台资源、海外公关、创作者网络、本地化、QA及主机移植。任何合作均需比较分成、版权、发行区域、最低承诺、营销投入和退出条款，不把尚未确定的发行资源计入基准销量预测。

### 核心受众与传播定位

市场进入优先触达两类已存在的相邻用户：一类是喜欢装修、收集、模拟经营和温馨动物题材的休闲玩家；另一类是对搜打撤的资源循环感兴趣、但不偏好高压硬核射击的轻度冒险玩家。传播不分别宣传两个孤立系统，而统一围绕“**去危险的废墟搜集，把破木屋装成末世最幸福的家**”展开，用野外危险与家园温暖的反差解释产品差异。

主要内容支点包括：

- **可视化装修成果**：房间改造前后对比、家具组合和玩家家园截图，适合短视频、直播及社区UGC传播；
- **紧张—治愈的双循环**：展示“外出搜集—遭遇危险—带着资源回家—继续装修”的完整体验，而非只展示单一战斗或摆放功能；
- **小动物情感反馈**：通过具体装修事件展示NPC记住并回应玩家行为，证明AI机制服务于情感体验，而不是附加聊天功能；
- **团队与开发过程**：持续公开Demo迭代、玩家反馈和美术制作过程，积累早期核心用户的信任。

### 分阶段市场进入路径

| 阶段 | 时间 | 核心动作 | 验证目标 |
| --- | --- | --- | --- |

### 渠道组合与预算纪律

发行与增长预算共60万元，其中20万元用于可归因的付费测试，20万元用于创作者合作，10万元用于商店与宣传物料，5万元用于Demo及平台活动，5万元用于社区与预备支出。渠道优先级为“**产品与Demo自然传播 → Steam平台活动 → 创作者与媒体 → 小规模付费归因测试**”，不以大规模信息流购买代替产品验证。

付费测试按“素材测试 → 商店页转化测试 → 渠道小规模放大”逐级释放，并统一使用Steamworks UTM记录可追踪访问和72小时内的愿望单/购买行为，同时观察活动前后的总愿望单基线。首轮规划以5—12元/个可归因愿望单作为测试区间，而非行业平均承诺；若CAC长期高于12元，或付费增长没有带来总愿望单同步提升，则停止放量，把剩余预算转向Demo质量、商店素材和创作者内容。

### 关键指标与决策门槛

**Beta结束前5万愿望单**作为基础经营观察目标，不是融资交付或销量承诺。团队不会用第三方估算的“愿望单÷销量”推导本项目转化率，也不会仅凭愿望单总量承诺销量。阶段复盘至少同时观察：商店访问与愿望单转化、愿望单来源结构、Demo下载与有效游玩、试玩完成率、退款率、Steam好评率、首发销量及自然流量占比。

## 七、核心技术

### 技术来源：自主研发 + 开源大模型集成

本项目的核心技术分为两个层面：

**1. 游戏引擎层（自主研发）**：基于 Unity 引擎进行全栈游戏开发，包括野外探索系统（AI怪物行为树、背包动态管理、撤离判定）、家园装修系统（自由摆放引擎、家具碰撞检测、风格匹配算法）、任务与成长系统等。所有核心玩法逻辑均为团队从零搭建。

**2. AI叙事层（开源模型 + 自研架构）**：小动物NPC的情感反馈系统采用"规则模拟层 → 叙事生成层 → 表现层"三层架构。叙事生成层调用兼容 OpenAI Chat Completions 协议的大语言模型（当前为 google/gemini-2.5-flash-lite），团队自主研发了结构化上下文构建、事件驱动触发、一致性校验与降级兜底等全套工程管线。模型可替换，架构不依赖于单一模型供应商。

**技术亮点**：

- 三层解耦架构：规则层 + AI层 + 表现层，各层可独立迭代、独立降级
- 一致性校验管线：生成 → 校验 → 重试 → 模板兜底，确保AI输出不与游戏事实冲突
- 事件驱动而非自由对话：AI只在玩家完成具体操作后触发反馈，避免"聊天机器人喧宾夺主"
- 低延迟优先：选用轻量模型，响应时间控制在游戏可接受范围内

## 十二、经营风险与对策

### 风险一：双赛道融合的用户接受度风险

**风险描述**：搜打撤玩家可能觉得冒险不够硬核，装修玩家可能觉得冒险有门槛。

**对策**：

1. 轻量化设计出现正向早期信号：19份样本的野外难度平均1.79/5（偏简单），同时全部受访者均表示期待后续内容；该结果仍需扩大样本验证。
2. 难度分层机制：休闲玩家专注低风险采集，硬核玩家挑战高难度地图。
3. 以装修为锚点：冒险是"为装修服务"的手段而非目的，降低休闲玩家抵触心理。

### 风险二：独立游戏市场竞争激烈

**风险描述**：Steam每年新上线游戏超万款，独立游戏突围难度大。

**对策**：

1. 品类定义者红利：媒体和KOL更愿意推荐"没见过的玩法组合"。
2. 双赛道交叉营销：同时触达搜打撤和装修两个玩家社群，获客渠道翻倍。
3. 赛事背书：2026光子游戏大赛概念赛道银奖提供行业认可与关注度。
4. 试玩反馈可用于迭代：保留正向信号，也公开操作、引导和节奏问题，以更大样本和行为数据继续验证。

### 风险三：AI技术的不确定性

**风险描述**：LLM调用的延迟、成本和内容质量可能影响游戏体验。

**对策**：

1. 降级机制已内置：生成 → 校验 → 重试 → 模板兜底，AI不可用时游戏正常运行。
2. 轻量模型优先：选用Gemini 2.5 Flash Lite等速度优先模型，延迟可控、成本极低。
3. 事件驱动而非自由对话：只针对明确游戏事件生成短反馈，质量可控性远高于自由对话。
4. LLM推理成本持续下降，我们的AI成本结构随时间改善。

### 风险四：小团队产能限制

**风险描述**：7人团队在内容生产速度和规模上无法与大厂竞争。

**对策**：

1. AI辅助内容生产：LLM大幅降低对话/剧情文本成本。
2. 聚焦核心体验，不做内容堆砌：少而精比多而糙更有竞争力。
3. 标准化内容管线：家具、地图、角色等内容边际成本递减。
4. 阶段性发行合作：通过发行商获取市场推广和本地化支持。

### 风险五：长线留存与内容疲劳

**风险描述**：装修类游戏可能面临"装完了就没动力继续玩"的留存问题。

**对策**：

1. 赛季制更新：新地图、新家具、新角色持续制造回归动力。
2. 双循环自带留存机制：搜打撤循环提供持续的"出门搜新东西→回家继续装"的驱动力。
3. 小动物情感绑定：AI情感反馈让玩家建立长期情感连接。
4. UGC潜力：家具自由摆放天然具备社区分享基础。
